依据《系统架构设计师教程（第 2 版）》的 5.1–5.7 组织，包含 42 个知识组和 159 道自测。每节可连续读图文、查看速查卡、完成自测；点击大图可放大查看。

下载时保留本目录的 HTML、`assets/`、`reader.css`、`reader.js` 和 `quiz-state.js`，随后打开 `index.html`。阅读无需安装 Skill 或启动服务器。配套 `.mmd` 是图解的可编辑源文件。

作答按小节保存在当前浏览器；换设备、换访问地址或清除浏览器数据不会自动迁移记录。页面作答不会上传到仓库或回写错题本。

各节末尾保留教材对应关系及公开来源；自测区分改编与自编，未确认原卷的题目保留说明。公开副本不附教材全文、私人笔记或制作日志。
