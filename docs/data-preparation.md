# 公开资料处理说明

本版本从两级学习资料中生成独立发布副本，保留 36 份章级知识点与速查文件、学习卡、真题转录和通用学习材料。

## 已处理

- 高级 20 个章级错题本、中级 1 个汇总错题本仅保留框架。
- 学习计划、进度看板、备考仪表盘和项目事实采集表初始化为空，不预设成绩、考试批次或学习日期。
- 移除知识点中的个人作答来源、错题回链、实际复习日期、会话痕迹及设备路径。
- 真实业务论文改为通用技术提纲；虚构论文的项目角色和数字明确标记为示例。
- 排除历史对话、转换交接记录、重复历史文件、用户截图及附件。
- 可定位的 Wiki-link 改为 Vault 相对路径；失效的小节锚点退回已有章节文件。缺失文件改为“公开包未收录该引用”的说明。

## 保留的边界

文件中原有的 OCR 损坏、回忆版、缺题、待补图、答案分歧等标记继续保留。未收录年份和缺失图片不会由初始化程序补造。

初始化脚本只复制发布包内的文件，不扫描或导出使用者已有的 Vault。重复初始化和 `--upgrade-skills` 都不会覆盖已有知识资料；升级选项仅替换所选平台的 Skill 文件。

## 验证

```sh
python3 scripts/validate_toolkit.py
python3 -m unittest discover -s tests -v
```

验证包括：5 个 Skill 的入口与引用、知识文件及 Wiki-link、21 个空错题本、缺失目标路径、全平台目录安装、预览零写入、重复安装、升级保留个人笔记以及符号链接拒写。实际 Agent 对话行为按 [交互验收](validation.md) 手动检查；这部分不由静态检查替代。
