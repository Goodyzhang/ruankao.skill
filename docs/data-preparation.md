# 公开资料处理与验证

1.0.0 将工具与完整学习资料分别发行。新增高级材料集中在 `materials/系统架构设计师/`；视觉复习册保留在 `artifacts/高级/系统架构设计师/`。原始学习目录只读，净化仅作用于发布副本。

## 分类与处理

| 类别 | 公开内容 | 排除与清理 |
| --- | --- | --- |
| 教材 | Markdown 正文、282 张引用插图、20 章索引与学习卡 | 去掉个人看板、项目底稿入口和设备路径；保留书目及 OCR 说明 |
| 笔记 | 20 章知识点、口诀、速查和专题图解 | 移除个人选择、Grill 记录、错次、掌握状态、复习日期和项目锚点 |
| 题库与案例 | 年度题目、专题案例、押题练习、参考解析、必要题图和结构化题包 | 移除作答、勾选、评分及练习档案；带个人进度截图用同题干净原图替换，无法替换时明示缺图 |
| 论文 | 真题、通用模板、课堂教学材料 | 个人论文、项目底稿及相关练笔整篇排除，不用更名或泛化后重新收入 |
| 视觉复习册 | 第 2–5 章、32 个小节、839 道自测及阅读资源 | 去掉个人答题来源、错次、状态和私有链接；排除制作日志、缓存、试制与未引用图片 |

原题干、选项、参考答案及已有 OCR、回忆版、缺题、缺图、答案争议说明继续保留。内容筛查不等于逐题重新校订，也不将推定训练评分改称官方细则。

## 工具兼容

工具包沿用原有 127 份初始化 Markdown 和 21 个空错题本，保留八个完整 Skill、实验室运行资源与可选 Harness。新增完整资料不由初始化脚本自动复制。

初始化脚本只复制包内种子与 Skill，不扫描或导出使用者已有 Vault。重复初始化和 `--upgrade-skills` 不覆盖已有知识资料；升级选项仅替换同名 Skill 文件。已有多端权威目录与发现桥接仍按自己的约定维护。

## 发布包边界

- 工具包及 Git 自动 Source code 压缩包：排除 `materials/`、`artifacts/`。
- 资料合集：教材、笔记、题库、案例分析、论文。
- 分类包：教材、笔记、题库与案例、论文四种；目录内部资源随包提供，跨类别引用指向在线文件。
- 视觉复习册：仅在 Git 仓库与在线站点提供。
- 两个 Release 分别提供自己的 `SHA256SUMS.txt`，不要求下载另一个 Release 的附件。

## 检查结果

- 6 项初始化测试与 3 项发布包行为测试通过，覆盖多平台安装、重复运行、升级保留个人资料、符号链接保护、分类边界和校验和。
- 工具结构、Markdown 链接、设备路径与凭证形态扫描、阅读模板和离线样章资源检查通过。
- 四章视觉复习册的题目、选项及答案键与来源保持一致；离线链接和资源检查通过。新增第四章已在浏览器验证导航、作答解析、刷新恢复、重做与图片放大。
- 文本筛查之外，题图与 PDF 另做个人信息、批注及表单检查；缺少干净题图的材料在各自正文中说明。
- 复习册 215 张 PNG 经本机 OCR、137 张 SVG 经文本检查，宽泛命中再核上下文；笔记另排除 4 张带个人错题注释的图，相关文字讲解保留。
- ETC、ORS、ES 三篇案例共缺少 5 处干净原图，已标明仅供解析复习，不适合作完整模拟题；未依据答案补造题图。

本版未改变讲题与阅卷流程，未重新执行所有历史 Agent 交互验收。历史行为与验证记录见 [更新日志](CHANGELOG.md)。

## 复现

在完整 Git 克隆的干净工作区运行：

```sh
python3 scripts/validate_toolkit.py
python3 -m unittest tests/test_init_toolkit.py tests/test_build_release.py -v
python3 scripts/build_release.py --version 1.0.0 --output ../ruankao-release-1.0.0
```

打包输出的 `toolkit/` 与 `materials/` 子目录分别对应两个 Release。
