## 视觉复习册与工具

第 2–5 章视觉复习册保留在 [在线目录](https://goodyzhang.github.io/ruankao.skill/artifacts/) 和完整 Git 仓库中，不在本资料包内。离线阅读可克隆仓库，再打开 `artifacts/index.html`。

AI 讲题、作答实验室和论文辅导工具单独在 [v1.0.0 工具 Release](https://github.com/Goodyzhang/ruankao.skill/releases/tag/v1.0.0) 下载。工具包保持原有初始化方式；资料包不会自动覆盖用户已有笔记和答卷。
