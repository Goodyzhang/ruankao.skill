# v0.10.0 — 论文范文按题意展开，批改核对论证

发布日期：2026-10-18。

本版将论文写作与批改的方法继续拆实：先明确题目要求证明什么，再检查文章主张、业务实例和验证结果能否相互支持。范文写成有过程的业务实践，评阅定位实际断点并给出替换稿。

## 本次更新

1. **从题目组织范文。** 保留原题对象、动作和范围，逐项回应全部要求，再组合重点实践。每段说明业务触发、本人决策、关键规则或状态、运行过程及验证，摘要从完成的主体回填。
2. **区分相关技术与有效论证。** 熟悉的架构或工具可以支撑不同题目；实例和结果必须作用于本题要解释的问题。只在原句前补题名，无法修复论证错位。
3. **明确 P01–P12 审查规则。** 覆盖题意、相关性、全面回应、业务行动、效果因果、技术机制、项目背景、摘要、结尾、材料完整性、写作口径与可追溯评阅。每个结论回指题目和原文，修改后再次核对。
4. **统一训练估分。** 没有本题正式逐点依据时，先固定 75 分训练表，再按证据给分。课堂成绩、教师估分和当前训练分分别记录，不能为了接近例文成绩调整权重。
5. **局部材料保留未知。** 区分原稿缺失、截图未展示、未还原和作者明确未写。只对可独立判断的单元计分，输出“已见部分得分／可评满分”，不将未知项记零或推断全篇不合格。
6. **结构按内容判断。** 十段式保留为训练预算；不因段数、题名出现次数或组合架构风格设置额外门槛。教学标签和评分表留在学习稿外围，考场稿连续成文。
7. **沿用授权写作口径。** 真实经历按已有事实修改；已授权模拟直接补足可行设计与结果，并检查内在一致性。设定说明留在元数据，正文保持完整叙述。

## 75 分训练表

| 维度 | 满分 | 主要判断 |
| --- | ---: | --- |
| A 题意与要求覆盖 | 20 | 对象、动作、小问及限定范围的实质覆盖 |
| B 理论及机制正确 | 20 | 定义、边界、交互、条件与异常处理 |
| C 业务实践与本人决策 | 20 | 实例颗粒、选择理由、实施过程及问题处理 |
| D 结果验证与前后一致 | 10 | 基线、条件、因果与摘要正文结尾的一致性 |
| E 结构与表达 | 5 | 内容职责、衔接、篇幅与可读性 |

同一缺口不另加“偏题”“关键词不足”或“段数不符”等重复惩罚。确定的机制错误可以指出；未展示的摘要、子题或结尾保持待核。
