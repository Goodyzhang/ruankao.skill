# v0.10.1 — 修复 Antigravity 已授权归档被拦截

发布日期：2026-10-20。

用户完成单题练习并确认归档后，当前运行时可能调用 `read_file` 或 `edit_file` 读取、更新章节。旧版可选 Harness 只识别旧工具名，PreToolUse 会拒绝这些调用，导致归档无法继续。本版补齐文件工具名称，并同步 Agent 收到的提示。

## 本次更新

- 新增 `read_file`、`edit_file`、`write_file`、`multi_replace_file_content`，保留 `ask_question`、`view_file`、`replace_file_content`、`grep_search`。
- 允许 `write_file`，以支持已授权归档时首次创建章节文件。Hook 按工具名称检查，不验证目标路径或授予归档授权；Agent 仍须核对本题或明确批次授权、章节目标、已有内容，并在写入后回读。
- PreInvocation 提醒、PreToolUse 拒绝说明和运行时规则使用同一份工具名单。已确认的单题流程继续拦截 `run_command` 和其它白名单外工具。
- 保留现有题目边界、卡片时序和任务路由：显式 Lab、题库批次、论文改稿与普通工程排查仍按各自流程运行。

本版仅修改可选 Antigravity Harness、相关测试与发布文档。八个 Skill、论文方法、Lab 服务及前端保持上一版内容；没有将个人工作区的旧脚本或专用站点规则复制到公开包。

## 安装与升级

下载 `ruankao-toolkit-v0.10.1.zip` 并解压。包内保留八个完整 Skill、实验室运行资源与 SMTP／POP3 样章，排除 `artifacts/`；在线复习册继续通过 GitHub Pages 提供。

**已安装旧 Harness 的工作区必须单独更新 Hook。** 仅更新 Skill 不会替换旧脚本。在新版发布包根目录执行（将目标改为自己的工作区）：

```sh
python3 integrations/antigravity-harness/install_harness.py --workspace "../YourVault" --force --dry-run
python3 integrations/antigravity-harness/install_harness.py --workspace "../YourVault" --force
```

Windows PowerShell 将 `python3` 换成 `py -3`。`--force` 会替换同名 Harness 脚本、规则及三个命名 Hook，保留其它 Hook。自行修改过同名文件时先备份并核对差异。更新后重新打开工作区并新建会话。

首次安装先按仓库 README 初始化 Skill 和资料，再运行 Harness 安装器；没有安装该可选模块的其它客户端无需安装它。
