## 本次变化

- **第六个 Skill：`soft-exam-review-book`**。按教材小节取材，结合真实错因讲机制、辨易混点；依次完成写作、图像、网页与独立复核。成品每节包含图文、速查、自测，支持中断续接和局部更新。
- **多代理协作**。Codex 统筹与核验，Gemini 优先创意写作，Claude Code 后备；核心漫画由内置 imagegen 生成，Grok 可承担少文字的辅助图。实际路径、模型和能力均需核对，可跳过缺少的协作 CLI。
- **旧 Skill 首次引导**。先检查指定或已绑定的位置与默认资料布局，再用真实候选卡片或绝对路径输入补全。普通文件夹可用；配置目录与本题归档授权分开，已确认的有效绑定不重复询问。
- **安装与升级**。复制六个完整 Skill 及 references、模板、图片、检查器。升级保留知识点、错题、复习册、作答记录和用户本地绑定。
- **Harness 路由**。章节制作、续写和修订不进入单题 Grill；实际环境配置卡不算练习答案。保留 v0.3.9 的推荐选项与收尾防循环修复。
- **README 漫画**。加入知识工作室与做题前后对比，保留“确认后自动归档”的实际行为。

## 升级

解压本版到独立目录，在发布包根目录先预览，再更新所选平台的 Skill：

```sh
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills --dry-run
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills
```

Windows 可用 `py -3`；平台参数也可选 `antigravity`、`claude` 或 `trae`。已有权威源与发现桥接的工作区沿用原组织，不能直接把完整 Skill 覆盖到桥接上。`--upgrade-skills` 会覆盖同名 Skill 的手工定制，但不覆盖已有学习资料。

使用可选 Antigravity Harness 时，单独更新其 Hook：

```sh
python3 integrations/antigravity-harness/install_harness.py --workspace "你的资料目录绝对路径" --force --dry-run
python3 integrations/antigravity-harness/install_harness.py --workspace "你的资料目录绝对路径" --force
```

完成后重新打开工作区并新建会话。旧 SMTP 样章与新章节模板的存储格式各自保留，本版不自动迁移旧自测数据，也不把页面答题记录写入正式错题本。

## 验证范围

通过 53 项 Python 行为测试（20 项 Harness、6 项安装、18 项路由、9 项校验器故障注入）与 10 项 Node 自测状态测试；六个 Skill 格式、包结构、链接、离线依赖及样章 JS 语法检查通过。发布压缩包解压后另做包结构与初始化检查。

首次接入进行了独立指令推演；Harness 使用可控事件重放。真实 Antigravity／其它 Agent 卡片 UI、Windows 客户端和 PowerShell 执行没有在本机实测；不把静态检查或测试替身称为真实 UI 验收。具体人工步骤见 [交互验收](../validation.md)。
