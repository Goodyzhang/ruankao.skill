# v0.4.1：复习册审稿强化与第五章知识库

本版把最近的复习册制作经验补进 Skill：生图前核对讲解密度和逻辑关系，生图后检查实际画面；计算、案例、自测各自保留完整条件。下载包同时收录系统架构设计师第五章，可直接离线阅读。

## 本次变化

- **生图前两轮改稿，再交 tutor 复核**。每轮都检查知识密度与逻辑对应，保留实际修改记录。图内知识文字少于 35 字触发低密度检查；35 字是下限，不是压缩上限。Gemini 按 tutor 方法检查易混条件和相邻知识，主编辑核实后再采用建议。
- **公式用小黑板讲完**。保留通用公式、符号含义、单位、成立条件和常数代入，逐步计算。核心图使用内置 imagegen 与鲸鱼娘；Grok 可承担少文字辅助图。生成器自行添加的表格、数字、箭头也要核验，修图后回看整图。
- **协作调用按真实能力判断**。Gemini 通过 Antigravity（`agy`）调用；缺少独立 `gemini` 命令不表示 agy 不可用。读取当前帮助与型号，完整匹配参数，区分 stdout、stderr、退出码与业务成功。请求型号和实际返回披露分别记录，失败按原有 Claude Code → Codex 路线接力。
- **审稿先核对当前案例**。回读完整题干、选项、解析、图注和前提，区分正文算例与独立变式。局部比较不能扩大为全局最优；不同的并列最优解按约束与目标值判断。审核建议记录采用、拒绝或待查及理由。
- **优先内建浏览器复核，保留作答**。沿用有效访问授权，切换页面后重新确认实际状态。纯正文、图片或解析修订保留兼容题目版本；测试不清空读者已有作答，最终页面须引用真正验收过的资产。

首次使用仍会核对资料目录与 CLI 的实际位置，支持真实候选、绝对路径输入和可选工具跳过。普通文件夹即可使用，不要求安装 Obsidian。单题讲解、归档授权与首次配置的边界沿用 v0.4.0。

## 升级

从本 Release 下载 `ruankao-toolkit-v0.4.1.zip`，解压到独立目录。在发布包根目录先预览，再更新已选平台的 Skill：

```sh
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills --dry-run
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills
```

Windows 可用 `py -3`；平台可选 `antigravity`、`claude` 或 `trae`。升级保留已有学习资料、复习册和本机绑定，但会覆盖同名 Skill 内的手工定制。已有权威源与发现桥接的工作区沿用原组织，不把完整 Skill 覆盖到桥接目录。完成后新建会话加载新版。

本版没有修改可选 Antigravity Harness；已经使用 v0.4.0 的用户无需重装 Hook。第五章与样章作为独立阅读资源随包提供，安装脚本不会用它们覆盖用户自己的复习册。
