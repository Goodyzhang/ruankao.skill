# v0.4.2：真实作答、交互模式与批量归档续接

本版将 [DreamLanter 的 PR #1](https://github.com/Goodyzhang/ruankao.skill/pull/1) 中有效的讲题与归档改动适配到当前工具包。首次使用引导、复习册路由、真实卡片与中断续接继续保留。贡献者署名保存在适配提交中。

## 本次变化

- 默认提示不再预填“我已选 C”。未提供作答时保持未知；答对后通过关键条件变化检验迁移，误选只构成候选错因。原题作答与每轮练习的字母、内容映射分别保存。
- 题源分级、章节定位、Grill 与写入契约按当前阶段加载。当前单题、历史对话整理和章节复习册仍分别进入原有入口。
- 文字模式需要用户明确选择；缺工具不自动切换。同步 Antigravity Harness，合法文字练习不再被重复补卡；切回卡片或进入新题时恢复相应检查。明确“只讲解”时结束本题。
- 批量归档授权绑定题号、目标和操作。逐题查重、写入、回读与保存状态，不重复索取适用授权；中断时先核对已有内容，补完半写条目，保留真实作答与人工备注。范围外的新题重新核对授权。

Harness 对明确授权的识别只用于减少重复确认，不授予文件写入权限；实际写入仍执行 Skill 的逐题契约。

## 升级

下载 `ruankao-toolkit-v0.4.2.zip`，解压到独立目录。先预览，再更新所选平台的 Skill：

```sh
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills --dry-run
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills
```

Windows 可用 `py -3`；平台可选 `antigravity`、`claude` 或 `trae`。升级保留学习资料、复习册和本机绑定，同名 Skill 内的手工定制需自行保留。已有权威源与发现桥接的工作区沿用原组织。完成后新建会话加载新版。

**已启用可选 Antigravity Harness 的用户还需更新 Hook**，在包根目录执行：

```sh
python3 integrations/antigravity-harness/install_harness.py --workspace "你的工作区绝对路径" --dry-run --force
python3 integrations/antigravity-harness/install_harness.py --workspace "你的工作区绝对路径" --force
```

未启用 Harness 时无需安装。升级保留其它命名 Hook；`--force` 允许覆盖同名 Harness 文件，先查看预览。

第五章与 SMTP／POP3 样章继续作为独立阅读资源提供，未在本补丁中修改。安装脚本不会覆盖用户自己的复习册。

## 验证范围

- 60 项 Python 行为测试与 10 项 Node 自测状态测试通过；新增 Hook 场景覆盖明确文字模式、真实模式卡返回、切回卡片、新题重置、只讲解收尾与批量授权。
- 独立代理在隔离环境执行默认入口、答对迁移及选项重排，保存正文与按题状态；缺工具时保留待确认状态，不推定用户作答、模式选择或授权。
- 独立临时知识库试验的 13 项文件检查通过，包括保留人工备注、补完半写条目、未知作答不补造，以及范围外题目不写入。再次续接未改变文件字节；试验暴露的归档与 Grill 优先级、指定补充章位两处歧义已修订并复核。
- 六个 Skill 格式、包结构与相对链接通过校验；发布包解压后检查安装、升级及原资料保留。

这些结果不等于真实宿主卡片 UI 验收。Antigravity／其它 Agent 客户端、真实 Gemini／Claude 调用、Windows／PowerShell 和浏览器交互回归本次未实测；手动步骤见 [交互验收](../validation.md)。
