# v0.4.3：Goal 协作授权与教学方法交接

本版修订 `soft-exam-review-book`，处理 Goal 中 Gemini 生图前复核反复要求确认教学方法发送范围的问题。已获授权的同一任务可跨小节、换图和中断续接复用协作范围；平台工具审批仍按正常机制执行。

## 本次变化

- **任务内沿用协作授权**。从真实用户请求或已接受方案回溯 Gemini 写作／tutor 复核授权，同范围交接不逐图重复弹卡。误发的重复卡可以依据已有授权续接，不伪造用户回答。
- **明确方法文档的发送范围**。检查后不含私人内容的 tutor／Grill 通用教学规范可按需要全文交接，同时提供当前提示词、公开知识、自编场景与待编辑稿件。本机路径、账户和私人定制先处理；原教材、私人知识库、聊天、业务材料和凭据不默认全文发送。
- **续接区分真实调用结果**。保留授权来源、交接材料及审批记录，区分未发送、已发送、待授权和误发重复卡。缺少授权的拒绝可补齐准确依据，沿正常机制针对性重提一次；仍被拒绝时保留待办，不把工具失败写成已审核。
- **Goal prompt 写清协作范围**。提供可供用户审阅的范围模板。用户实际提交或明确接受才构成授权，Skill、配置或代理声明不能自行授予权限。

首次使用引导、单题卡片和批量归档沿用 v0.4.2。第五章与 SMTP／POP3 样章继续随包提供。

## 升级

下载 `ruankao-toolkit-v0.4.3.zip`，解压后先预览，再更新所选平台的 Skill：

```sh
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills --dry-run
python3 scripts/init_toolkit.py --vault "你的资料目录绝对路径" --platform codex --upgrade-skills
```

Windows 可用 `py -3`；平台可选 `antigravity`、`claude` 或 `trae`。同名 Skill 内的手工定制需自行保留；已有学习资料、复习册和本机绑定保留。权威源与发现桥接的工作区沿用原组织。完成后新会话加载新版；正在运行的 Goal 需重新读取新版 Skill 与引用文件。

本版未修改 Antigravity Harness，已安装 v0.4.2 Hook 时无需重装；更早版本的升级参见 [v0.4.2 发布说明](v0.4.2.md)。

旧 Goal 若缺少真实授权依据，可补充：

> 允许本 Goal 将检查后不含私人内容的 tutor／Grill 通用教学方法、当前提示词和公开知识交给本任务已确认的 agy/Gemini 复核。重新读取新版 soft-exam-review-book 并继续，同范围不重复询问，仍按当前工具审批机制执行。

## 验证范围

- 60 项 Python 行为测试与 10 项 Node 自测状态测试通过；六个 Skill 格式、包结构、相对链接及资料保留校验通过。
- 独立隔离演练检查已有授权、未授权及准确重提后仍被拒绝三个场景；16 项实际文件／状态检查通过。通用方法和完整提示词保真，原私人段落未进入交接包，旧卡未伪装成已回答。
- 实际 agy 调用读取帮助与模型列表，请求 `gemini-3.8-flash-high`，通过正常审批提交两份已检查的通用教学方法；退出码 0、业务状态 `SUCCESS`，返回非空复核清单。响应未披露实际底层模型，不据此断言实际路由。
- 发布包检查 ZIP 完整性及与最终提交逐文件一致，解压后通过包校验、隔离安装和升级保留检查。

实际 CLI 试验验证了本轮调用，不保证其它任务一律获批。真实宿主卡片 UI、Windows／PowerShell、跨会话 Goal 调度与真实服务断流恢复本次未实测；合成场景不等于这些验收。手动步骤见 [交互验收](../validation.md)。
