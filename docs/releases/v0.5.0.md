# v0.5.0：软考作答实验室与精简发布包

新增 `soft-exam-lab`，为系统架构设计师案例题提供本机作答环境和严格逐点评阅。当前 Agent 完成选题、初评与自检，不要求额外模型 API。普通单题、学习计划、历史导入与复习册保持各自入口。

## 本次变化

- **显式启动**：仅 `$soft-exam-lab`、`@soft-exam-lab` 或“使用 soft-exam-lab”启动。一道指完整案例大题；一套默认三道专题案例题，方向或数量不清先弹卡。已有草稿默认续做，提交但未评阅的场次继续批卷。
- **可靠取材**：本地题库 → 历史错题 → 联网补缺。核验身份、完整小问、分值、原图与可靠解析；材料不全不补造真题。作答前冻结版本化私有评分表，不向作答网页公开参考答案。
- **本地作答**：预构建 React 页面与 Python 标准库服务，仅绑定本机。支持 Markdown／公式预览、题图放大、Excalidraw 绘图、真实保存状态、计时暂停、刷新恢复与提交冻结。保存失败保持可编辑，口头“已提交”不替代冻结文件。
- **严格评阅与归档**：逐点定位实际文字、图形和计算证据，遗漏不得分；参考估分与严格训练分分别展示，同因不重复叠罚。报告包含原答卷、正确表述、失分原因、图表和强化 prompt。材料争议标待核验，完成归档并回读后才关闭当前入口，保留历史档案。
- **接入与初始化**：七个完整 Skill 随包安装；实验室禁止隐式调用，Harness 不将单题工具限制带入实验室。README 提供可复制的安装后初始化 prompt，探测实际 SOP 根目录和资料位置，不含作者本机绝对路径。
- **精简 Release**：安装包及自动生成的 Source code 通过 `export-ignore` 排除 `artifacts/`。知识库仍在 Git 仓库和 GitHub Pages，SMTP／POP3 样章继续随包提供。实验室运行所需的脚本、样式和字体保留，使用者无需 npm。

## 安装与升级

下载本 Release 的 `ruankao-toolkit-v0.5.0.zip`，解压到与目标工作区分开的目录。在解压目录运行：

```sh
python3 scripts/init_toolkit.py --vault "{请在这里填写你的工作区或 Vault 路径}" --platform codex --dry-run
python3 scripts/init_toolkit.py --vault "{请在这里填写你的工作区或 Vault 路径}" --platform codex
```

将占位符替换为真实路径；已有用户更新 Skill 时增加 `--upgrade-skills`，先保留同名 Skill 内的手工定制。平台可换成 `antigravity`、`claude` 或 `trae`，Windows 用 `py -3`。已有知识点、错题、计划和本机绑定默认保留。权威源与发现桥接的工作区沿用原组织，不覆盖桥接为另一套 SOP。

Antigravity 已安装可选 Harness 的工作区还需单独更新路由，先预览再执行：

```sh
python3 integrations/antigravity-harness/install_harness.py --workspace "{请在这里填写你的工作区或 Vault 路径}" --force --dry-run
python3 integrations/antigravity-harness/install_harness.py --workspace "{请在这里填写你的工作区或 Vault 路径}" --force
```

在目标工作区新建会话，使用 [README 初始化 prompt](../../README.md#安装后初始化-prompt可复制)，然后另行显式启动：

```text
$soft-exam-lab 为我来一道系统架构设计师软件系统设计的案例题真题，就做一道。先确认题库与练习档案位置。
```

真题库不完整时需要补充完整题干、图示和可靠解析；本版不附赠未经核验的可作答真题。

## 验证与边界

99 项 Python 行为测试与 10 项 Node 状态测试通过。七个 Skill 格式、包结构、资料保留和链接校验通过，恢复包的 371 个文件、25 项映射无哈希错误。发布包另检查导出排除项、ZIP 完整性、与最终提交逐文件一致，以及解压后的校验、安装和升级保留行为。

内建浏览器使用自编隔离案例完成正文／公式、实际绘图、PNG 导出、保存、刷新续做、交卷冻结、双分数报告及归档闭环；桌面 1280 和平板 820 宽度检查通过。固定语义基线由当前 Agent 手工判定，脚本校验证据与加总；脚本不承担语义评分。开发独立复核不等于生产使用双代理阅卷。

正式真题闭环、真实宿主卡片 UI、Windows／PowerShell恢复与物理触控未实测。内建浏览器不允许直接访问 `file:`，离线报告本地依赖和导出／导入已检查，直接打开的渲染未实测。报告最后新增的来源级别、小问标题及证据定位按钮已构建，未重跑局部 UI。详细范围见 [实验室验收记录](../soft-exam-lab-validation.md)。
