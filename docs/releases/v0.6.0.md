# v0.6.0 — 浏览器题库整理与在线复习册

发布日期：2026-10-05。

## 新功能

新增第八个 Skill `soft-exam-bank-ingest`。在内建浏览器登录“软考〇人”，打开章节后即可显式点名整理案例题与论文题，支持题号区间、同案例多小问合并、原图与副本标注、考场答案、逐问 tutor 解析、完整应试模拟论文和中断续接。

~~~text
@soft-exam-bank-ingest 为我完成当前打开页面79～85题的案例题和论文题整理。
~~~

需要视觉、真实浏览器与本地保存能力。首次缺目录时提供候选或手动路径；只阅读、展开解析与导航，不代填网站笔记或交卷。没有真实个人错误不增加错次，模拟项目设定不回写真实底稿。完整核验的网站材料可以 `web-bank` 进入普通案例练习；未核实考试身份不能满足“历年真题”请求。

安装、Harness 与题包契约同步更新，普通单题、复习册和既有卡片续接保持原流程。安装器新增 `--platform zcode`，复制八个完整 Skill 到 `.zcode/skills/`；默认保留已有个人资料，Skill 升级仍需显式 `--upgrade-skills`。

README 按工具介绍、Skill 分工、在线资产目录、安装使用、更新日志重排，并加入现有三张宣传图片。欢迎其它考生提交勘误与各科章节。

## 安装与升级

下载 `ruankao-toolkit-v0.6.0.zip`，在独立目录解压，然后按 README 初始化。已有资料升级示例：

~~~sh
python3 scripts/init_toolkit.py --vault "../RuankaoVault" --platform zcode --upgrade-skills --dry-run
python3 scripts/init_toolkit.py --vault "../RuankaoVault" --platform zcode --upgrade-skills
~~~

其它平台使用 `antigravity`、`codex`、`claude` 或 `trae`。旧 Harness 需单独按其说明更新。Release 安装包与自动生成的 Source code 均排除 `artifacts/`；在线作品从仓库或 Pages 单独取得，SMTP／POP3 样章继续随包提供。
