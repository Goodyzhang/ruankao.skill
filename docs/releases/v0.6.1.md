# v0.6.1 — 作答区撤销与草稿恢复交互修复

更新日期：2026-10-08。

## 修复与行为

原先每次输入都会重新读取浏览器草稿，正常编辑也触发“恢复浏览器未保存稿”，提示随着自动保存出现、消失。现在只在打开页面时读取恢复候选，点击恢复后收起提示。

作答区右侧常驻“撤销”，撤回当前小问最近一次正文编辑，最多保留20次。各小问分别记录；暂停、未开始作答、交卷或没有记录时按钮禁用。撤销结果继续自动保存，刷新保留已保存正文，撤销记录从新的编辑开始累积。中文输入合成阶段合并为一次正文编辑。

随包更新前端源码、预构建 JavaScript 与依赖许可说明，使用者仍无需 npm。

## 升级

从 [v0.6.1 源码安装包](https://github.com/Goodyzhang/ruankao.skill/archive/refs/tags/v0.6.1.zip) 获取更新，按 README 的 `--upgrade-skills` 步骤安装。

已有作答场次先保存草稿，让 Agent 将新版 Skill 的 `assets/frontend/dist/` 更新到该场次的 `public/static/`，再刷新页面。沿用当前场次及其题包、评分表和答卷；后续新场次会自动复制新版前端。

## 验证

- 2026-10-08 在内建浏览器、隔离的回环 HTTP 作答场次中复现旧按钮闪烁，再验证修复；验收答卷仅保存在临时目录。
- 实际验证：按钮常驻、单步撤销、连续25次编辑仅能撤销最近20次、不同小问记录隔离、暂停恢复、撤销后的保存及刷新恢复。
- 浏览器验收通过后已关闭临时服务并清理测试场次。直接打开 `file:` 页面的渲染不属于本次实测结果。

本次推送前串行执行的35项实验室 Python 测试通过；八个 Skill 与资源、127份初始资料、21份空错题模板及文档链接、包隐私检查通过。Skill格式校验与差异空白检查通过。既有其它功能的验收见 [v0.6.0](v0.6.0.md) 与 [实验室验收记录](../soft-exam-lab-validation.md)。
