# v0.8.1 — Tutor 卡片续接与换题提醒修复

发布日期：2026-10-10。

## 讲解与卡片续接

需要 Grill 门控、练习或归档确认时，先给可见讲解或反馈，再在本轮结束前实际调用当前客户端可用的提问工具。正文预告、伪调用格式不能替代工具事件；正文和调用可以记录在不同消息中。工具已有真实返回时继续相应步骤，待答时等待。

漏卡时沿用已发送的讲解，补真正缺失的调用。卡片已显示但正文缺失时补必要正文，不重发卡片；可选 Antigravity Hook 只提示核对，不强制续写，也不采用固定的 20 字阈值。讲解是否充分仍按主 Skill 判断。

未作答、只讲解、明确结束、工具不可用与已发卡待答分别处理。只说“不 Grill”仅跳过练习，归档仍按授权或确认流程继续。“只看解析”的真实门控答复现在能正常收尾，修复了随后被 Hook 催发新卡的问题。

## 换题与授权

新题使用独立状态。上一题确有未完成步骤时，在新题正文第一行简短提醒一次实际步骤；已经授权归档但尚未写完时，不再误报为“尚未确认归档”。提醒不自动续做或归档，不把旧卡片答复、范围外授权带入新题。

Hook 提供的是前题待核对线索，Agent 仍须核对题目标识和逐题状态。只讲解且已讲完、拒绝归档或已经完成归档的题目不继续挂起；读取文件中的示例文字不能充当用户卡片选择。

## 审阅后合入的修正

本次在当前发布版基础上合入 tutor 与 Hook 补丁，保留文字模式、目录选择、批量授权、复习册、Lab 和题库整理的既有处理。

审阅修正了单条 API 消息与工具名的硬编码、结束条件之间的冲突、已发卡片的重复补发、悬挂提醒的错误状态描述。素材维护按具体请求识别；明确讲解当前题目或已有作答的请求，不因题目涉及“备份”“脚本”等词语而被排除。

## 更新

下载 `ruankao-toolkit-v0.8.1.zip`，按 README 更新 Skill。若已使用可选 Antigravity Harness，再从解压后的工具包目录执行：

```sh
python3 integrations/antigravity-harness/install_harness.py --workspace "你的工作区路径" --dry-run --force
python3 integrations/antigravity-harness/install_harness.py --workspace "你的工作区路径" --force
```

Windows 可使用 `py -3`。安装器只更新自己的命名 Hook 与配套文件，保留其它 Hook。新对话重新读取 Skill 与运行时规则；资料、答卷与个人笔记保持原有内容。
