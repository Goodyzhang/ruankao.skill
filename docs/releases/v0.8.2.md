# v0.8.2 — Lab 参考答案与评分依据一致性修复

发布日期：2026-10-10。

## 修复内容

旧版允许评阅文件覆盖评分表中的完整参考答案，而逐点反馈继续读取冻结采分点。因此，两份材料出现分歧时，报告会同时显示相反的答案。本补丁移除独立覆盖入口，让完整答案和采分点统一保存在同一版私有评分表中。

参考答案的 `sources` 必须与本题采分点来源一致；各点 `correct` 从完整答案正文提取。报告的来源说明由这些依据生成，不采信另写的“官方答案”标签。案例、选答题及论文都使用同一流程。

出报告前，Agent 必须逐题回查原始资料，核对答案、采分条件、同义边界、判定与风险提示，记录覆盖全部采分点的 `reference_checks`。运行器拦截来源分叉、答案片段不匹配、缺少核对、重复或跨题核对及未解决冲突；失败时保留已有报告。资料争议可保留 pending，对应点同样待核验，不给出确定总分或合格结论。

程序检查的是数据绑定与核对记录，全文语义仍须 Agent 实际审阅。对填空顺序、分类归属、候选集合、方案条件、技术版本及额外解释的审阅已写入 Skill，不能用校验通过代替事实核实。

## 升级与既有场次

下载 `ruankao-toolkit-v0.8.2.zip`，按 README 更新完整 Skill。用户仍只需 Python 3.9+，前端沿用已构建资源，无需 npm。

已有静态报告可以继续阅读。旧评阅若在 evaluation 中保存独立答案，重评前须先核实并通过 `revise-rubric` 移入新评分表，填写 `sources`，让 `correct` 对应正文片段；随后更新 evaluation.rubric_hash，移除 evaluation.reference_answers，完成 reference_checks，再运行 grade。原始提交、旧评分表与历史报告保留。
