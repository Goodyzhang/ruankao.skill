# v0.9.0 — 论文批改从扣题与业务实践出发

发布日期：2026-10-15。

## 本次学到并固化的方法

论文需要回答题干、说明项目怎样运转，并让阅卷者看见架构师的判断与措施。批改时先做逐项覆盖表，检查论述是否充分、技术机制是否正确、业务实例是否具体，再修改摘要、结构、字数和语言。关键词齐全或段落整齐，不能代替实质论证。

1. **先扣题。** 将每条小问拆成可检查的要求，原文逐项定位；题干给五个方面就全部回应，再选择重点或组合成三个实践论点。
2. **写业务过程和本人行动。** 每个实践说明业务问题、原理与选择、本人措施、调用或数据流程、实施问题及验证效果。减少只有技术名称和“提高效率”的空泛段落。
3. **按已确定的写作口径批改。** 真实经历版本保真；应试模拟可设计合理的项目、技术和效果，评阅其可行性、自洽性与题意，不要求真实仓库证明。模拟说明放在元数据或独立写作说明，正文保持完整考场表达。
4. **结构服务于内容。** 默认十段含两段摘要和八段正文；摘要第一段写项目、作用及职责，第二段依次概括三个论点与效果。题目要求优先，十段式不成为额外硬性评分条件。
5. **统一名称和数据。** 首选教材规范术语，内部代号改成功能名称；明确子系统、模块、构件与服务职责。金额、周期、团队、预测时域以及效果的分母、基线和比较条件保持一致。
6. **把反馈变成可执行修改。** 给出主要问题、原文证据、影响和替换文本；用户要求全文时，交付完整摘要与正文，再核对全部要求和字数。

## 入口与兼容

- `soft-exam-architect-prep` 新增论文写作与批改参考，单篇论文题目也走该入口；普通改稿不自动建立 Lab 场次。
- Lab 的论文评分规则及阅卷 SOP、题库模拟范文和历史素材归档接入同一参考，修正 prep 与应试模拟口径冲突。
- 修复可选 Antigravity Harness 把论文审题与批改误判成单题讲解的问题；保留论文中客观知识题的 tutor 路由。
- 保留 Lab 的冻结答卷、版本化评分依据、原文批注、完整参考答案与按原卷计分机制。
- 没有官方逐点权重时使用明确标识的推定训练表；课程经验、建议字数和软件限制传闻不包装成官方评分规定。

完整规则：[论文写作与批改](../../skills/soft-exam-architect-prep/references/paper-review.md)。

## 升级

下载本版 `ruankao-toolkit-v0.9.0.zip`，沿用初始化器的 `--upgrade-skills` 升级完整 Skill 目录；已有知识点、错题本、论文底稿和本地绑定保留。采用权威源与发现桥接的工作区，应合并到权威目录，保留桥接。已打开的聊天重新读取更新后的入口与论文参考。

已安装可选 Antigravity Harness 的工作区，还需从本版发布包根目录运行 `python3 integrations/antigravity-harness/install_harness.py --workspace "目标工作区" --force --dry-run` 预览，再去掉 `--dry-run` 更新；Windows 可将 `python3` 换为 `py -3`。该步骤保留其它 Hook。
