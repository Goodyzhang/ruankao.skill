# 1.0.0 · 软考学习工具

发布日期：2026-10-23。

本版将学习工具与系统架构设计师资料分开发行。工具包保留八个完整 Skill、安装脚本、本地作答实验室、可选 Antigravity Harness、原有初始化种子与空白记录；新增完整教材、题库和教学笔记由独立资料 Release 提供。

## 下载

- **本 Release：** `ruankao-toolkit-v1.0.0.zip`，用于安装或升级工具。
- **学习资料：** [materials-v1.0.0](https://github.com/Goodyzhang/ruankao.skill/releases/tag/materials-v1.0.0)，可选择合集或教材、笔记、题库与案例、论文分类包。
- **视觉复习册：** [在线阅读第 2–5 章](https://goodyzhang.github.io/ruankao.skill/artifacts/)，也可克隆完整仓库离线阅读；图片较多，不进入 Release ZIP。

## 本版整理

README 按资料入口、下载选择、安装、Skill 分工、版本记录和来源整理；详细步骤与初始化 prompt 移入 [安装说明](../installation.md)，旧版本记录移入 [更新日志](../CHANGELOG.md)。

新增的 `scripts/build_release.py` 从干净的 Git 工作区分别构建工具包、资料合集与四个分类 ZIP，并生成 SHA-256 清单。Git 自动 Source code 包与工具包排除 `materials/`、`artifacts/`，完整材料保留在仓库。

## 安装与升级

在解压目录运行：

```sh
python3 scripts/init_toolkit.py --vault "../RuankaoVault" --platform codex --dry-run
python3 scripts/init_toolkit.py --vault "../RuankaoVault" --platform codex
```

升级同名 Skill 时加 `--upgrade-skills`。Windows 将 `python3` 替换为 `py -3`；其它平台参数与已有权威目录说明见 [安装指南](../installation.md)。已有知识点、错题本、论文和进度继续保留。

本版不改变 Skill 的讲题、作答或阅卷流程。资料内容检查、安装验证与打包结果见 [资料处理说明](../data-preparation.md)。
