# soft-exam-bank-ingest 验收记录

日期：2026-10-05。验证在 macOS、Python 3.9、本机 Codex 内建浏览器进行。本文记录开发验收；发布信息另见 [v0.6.0](releases/v0.6.0.md)。

## 结果

- 新增权威 Skill、5 份按需 references、Python 保存/续接/导出脚本与显式调用元数据；工作区发现桥接、Harness、路由和恢复包已更新。
- 当前工具包118项Python行为测试通过，其中新入口19项。覆盖保存、续接、合并凭据、人工备注、同批增补、公开资源隔离、真题Gate及路由；安装到三种平台目录、重复安装和升级保留笔记/绑定也通过。
- 独立代理以合成10/11题验证61项保存、续接、私有资料隔离和论文流程，全部通过。其探针不等于正式网站验收，也没有冒称短篇探针是完整应试作文。
- 已实际用内建浏览器读取网站133～135的完整题面、原图与展开解析，合并为一整道25分案例；核对136已是另一案例。正式案例三问、八空原图/标注稿、教材/SEI语义和小问分值已复核，正文与结构记录相符。
- 实验室实际准备3小问题包，内建浏览器切换三问、检查原图放大；未替用户答题、交卷或评阅。网页没有参考解析/评分表；真题请求实际拒绝 web-bank。临时服务仅绑定127.0.0.1，验收后已关闭并移除服务回执。
- 完整微服务模拟论文约335字摘要、约2600字正文，覆盖题面5项要求。独立复核后修正输入数据版本与事务消息边界，保留旧版；不回写真实项目底稿。

## 已修复问题

pending 台账漏查原图哈希、同批已完成案例无法逐阶段更新、save丢阶段history已复现并复验。管理区人工改动须读取合并后以新版本与观察哈希保存；区外人工内容保留；相同版本重复写不改正文或台账。半途完成Markdown、尚未写回执时可重播恢复；未完成不导出。公开题包注入答案、引用答案图和跨场次私有资源均被拒绝。

正式效用树没有逐空官方细则，已使用有依据的等价场景训练口径；网站补注13和云服务依赖的不同分析角度分别说明。资料为普通练习，不据此认证真题身份。

## 未实测

Windows/PowerShell恢复脚本、其它Agent的真实浏览器与卡片UI、触控和外部本机标注软件尚未实测。真实网站的验证码/登录失效、懒加载失败、导航连续失败与整节长期运行未实测；这些分支采用指令前推和合成状态验证。相近数值题与区间同案例扩展使用合成资料验证，未在真实网站额外取材。

网站闭环为开发取材与正式合并验收，逐阶段中断恢复由合成夹具验证，不将一次成功页面读取泛化为所有客户端兼容。Markdown文件链接由脚本检查，Wiki标题由模型实际对照。
