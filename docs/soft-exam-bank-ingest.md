# 软考题库整理

显式入口 soft-exam-bank-ingest，完整 SOP 在 skills/soft-exam-bank-ingest/。案例、论文整理与单题 tutor 分开；已启动批次可直接“继续”，以台账和真实页面恢复。

## 安装与首次使用

使用现有 scripts/init_toolkit.py 安装全部八个 Skill。已有笔记默认保留；升级用 --upgrade-skills，绑定不进入发布包。案例导出需要 bank-ingest 与 lab 同级安装。Python 3.9+ 标准库用于保存与导出；模型必须能实际看题图，浏览器需要已登录到用户指定章节。

在内建浏览器中登录“软考〇人”，打开目标小节后发送：

~~~text
@soft-exam-bank-ingest 为我完成当前打开页面79～85题的案例题和论文题整理。
~~~

不指定区间时可说“整理本节剩余的案例题和论文题”。无需重复粘贴 SOP；Skill 自行检查能力、确定目录和续接状态。ZCode 安装使用 `--platform zcode`，新会话中选择这个 Skill；其它平台按实际发现方式显式调用。

没有特定浏览器/绘图 CLI 不阻塞可用原生工具；缺视觉或浏览器访问能力则说明缺口，选择更换模型或连接现有工具。不能仅凭模型名判定视觉可用。

## 顺序和资料

读取完整题干与原图→存来源草稿→展开解析→解答或写作→自审→入库回读→下一题。处理指定范围；同案例被区间截断时补齐前后小问，记录扩展，不能自动跨节。相同背景条件变化必须保留版本，不依赖相似度自动合并。

案例保留全部小问、分值、网站映射、源解析、考场答案、采分要点与详细教学。推定训练分值单独标注。原图不覆盖，标注副本保存 SVG/PNG，与公开题图隔离。论文按题面完整作文；默认约300字摘要、约2300字正文为训练目标，以具体项目、本人行动与技术取舍扣题。模拟设定单独记录，不回写真实项目底稿。

## 脚本

scripts/bank.py 只负责原子保存、回读、哈希、版本、续接与实验室导出；不解题、不作文、不语义合并。记录契约见 [records.md](../skills/soft-exam-bank-ingest/references/records.md)。管理区人工改动默认阻止覆盖，模型合并后以新版本和已观察哈希继续；管理区外备注保留。

实验室出口包含 public/pack.json 与 original 图，private/rubric.json 独立。服务仅公开 public；pending/缺图/未知解析/未解决争议不能导出。web-bank 只能普通训练，--require-true 拒绝。论文不进入首版案例作答运行器。
