# 软考案例与论文作答实验室

显式 `$soft-exam-lab`、`@soft-exam-lab` 或“使用 soft-exam-lab”启动。支持系统架构设计师高级案例分析与论文；普通讲题、章节复习册和历史归档保持原路由。

```text
$soft-exam-lab 为我来一道软件系统设计案例题真题，做一道，使用自由计时。
```

指定年度案例或论文真题时按原卷整卷准备：显示候选题，按必答与选答规则计分，正式卷满分75分。论文候选数量、字数按实际原卷。明确单题时一道是完整案例及全部小问，未指定年份的一套默认三道专题组卷。没有方向或数量时，Agent实际弹卡确认；可选查漏补缺、复习或新考点。首次确认题库和档案位置；普通文件夹也可使用，无需Obsidian。Python 3.9+运行本机服务，使用者不需要npm或模型API。

## 作答

Agent从本地真题库、历史案例错题、联网补缺依次选择。缺必要题图、解析或身份依据不能作为完整真题。可靠答案已有但缺逐点分值时，使用明确标为推定的训练评分表，作答前冻结。

内建浏览器打开本机地址；不可用则用同一链接在普通浏览器打开。页面顶部显示原卷要求和合格线。启用原卷按题号超选规则的案例可直接开始并作答全部候选题；其它卷按原卷选题方式开始。当前小问会在右侧作答区上方重复显示；论文分别填写摘要和正文，可切Markdown/公式预览。绘图区支持常见图形、文字、箭头、撤销和缩放，保存可编辑图稿与同一份PNG。题图可以放大或设底图。默认自由计时可暂停，限时模式先确认时长，刷新不重置。

作答区右侧的“撤销”始终显示；每个小问最多保留 20 次正文编辑记录，没有可撤销记录或计时暂停时禁用。撤销结果与普通输入一样自动保存。刷新页面保留已保存正文，撤销记录从新的编辑开始累积。浏览器草稿恢复提示用于打开页面时发现的未保存草稿，正常输入不触发。

交卷先保存再冻结，失败时保留输入。回到Agent选择“已提交”，Agent核对本场真实提交文件再评分。未提交练习默认续做；明确新开保留旧稿并创建空答案场次。Python不可用时用离线页导出实际答卷JSON，交给Agent验证导入；离线页面不会直接写回磁盘。

说明“按照真题评分标准”时，Agent 按原卷核实计分与超选规则。2018案例卷取试题一及题号最小的两道已答选答题；多答题单列批改，不进入网页总分和主要失分排行。文字、附件或用户图稿均可表明已经作答，纯题图底图不算。少答仍以75分为分母。

## 评阅与档案

当前Agent逐采分点初评和自检，如实标单代理评阅。没有写出的必要机制不推断；合理同义表达可给分，错误解释或方向冲突不得分。报告分开显示参考估分和严格训练分，训练规则去重同因，不冒充官方扣分。待核验不能当0分。

完整答案和采分点使用同一份已核实依据，保存在私有评分表中。当前 Agent 先阅读原始资料，再从完整答案提取各点正确表述，出报告前逐题核对来源、空号、候选集合、条件、解释与实际判定。运行器检查版本、来源集合、答案片段及核对覆盖，拒绝评阅文件独立覆盖答案；语义判断仍由 Agent 完成。资料冲突需记录取舍，不能凭“官方答案”标签认定可靠。无法核实的部分保留待核验。

逐问看带批注的原答案、完整参考答案、正确表述、失分原因和评语。绿色突出得分依据，黄色提示表述风险，红色标出明确错误；中性部分不填色。右侧引文高亮同一词句，点击定位到左侧原文；原始 Markdown 可展开查看。黄色不额外扣分，红色按已有评分依据说明具体影响。来源仅有笼统建议时，由当前Agent根据可靠依据补成具体应试答案；论文给出完整摘要和正文范文，明确生成方式与模拟项目。正式卷以参考估分对照当期单科合格线，按已知失分排列小问与考点；未选题不算遗漏，待核验不判失败。小问分数条形图、采分点分布和考点覆盖来自实际评阅；三个以上已考查维度才显示雷达图。强化prompt可复制到新对话，报告不会强制Grill或自动新建会话。

本场完整档案保存到已确认的档案根，新绑定默认使用科目的“练习档案”。已有案例档案及绑定位置继续保留。可靠失分点按既有章级契约去重归档，知识点正文不自动重写。回读完成才清当前入口、关闭本场服务。历史和离线报告保留。

## 维护者

完整SOP在 [Skill入口](../skills/soft-exam-lab/SKILL.md)。前端源码和锁文件在 `skills/soft-exam-lab/assets/frontend`，运行npm ci、npm run build；构建产物和字体随安装包分发，不携带node_modules。后端只依赖Python标准库。固定模板、数据和状态分别维护，首版无抽象工厂。

运行器提供prepare、serve、status、grade、finalize、import-answer、revise-rubric。HTML用于展示，冻结JSON用于阅卷。评分事实错误允许版本修订重评，保留原答卷和历史报告。服务只绑定127.0.0.1，资源白名单不包含参考解析、评分表及其它知识库。

来源与采用方法见 [research](../skills/soft-exam-lab/references/research.md)，实际验证与未测范围见 [本版验收](releases/v0.8.3.md)。GitHub 发布需用户明确授权。

## 原卷规则与评分依据

2018案例一必答、二至五选二，论文四选一，单科均75分、45分合格。具体来源、其它批次核验及论文审题见[年度试卷规则](../skills/soft-exam-lab/references/paper-rules.md)。官方未公开逐点权重时明确采用推定训练评分，不把网络流传的固定比例称为官方细则。

完整升级 Skill 后，新评阅使用新规则。旧的全题练习保持原有档案，用户要求按真题计分后，可通过 `exam_reassessment` 补记规则与原因，在同一场次按实际已答题重新求和，原始答卷保留；不按比例换算。旧场次的完整答案需核实后通过 `revise-rubric` 纳入评分表，更新本次评阅版本并补齐逐题核对记录后生成新报告；原答卷和历史版本保留，已有静态报告仍可阅读。
