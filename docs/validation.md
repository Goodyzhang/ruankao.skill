# 人工行为验收

本文件提供自编题与验收步骤，不包含历史会话或考试真题。请在独立测试会话和临时 Vault 中执行；不要把尚未执行的场景标成通过。

## 测试准备

1. 安装整个 `soft-exam-question-tutor` 文件夹，重新打开会话。
2. 让 Agent 读取主 Skill，确认当前结构化提问工具是否实际可用。
3. 归档测试先创建隔离测试目录，再明确指定其实际绝对路径；单题写入授权不包含进度看板或其它文件。
4. 保留可见正文、工具调用及工具返回的时序。内部分析与工具摘要不算讲解。

## 自编题

每个独立场景可使用以下完整题目；它属于算法基础练习，题源应标为“软考知识域相关但题源未确认”。

```text
某算法对长度为 n 的数组进行一次从头到尾的遍历，每个元素执行常数次操作，
没有嵌套循环。只考虑这次遍历，时间复杂度为多少？
A. O(1)
B. O(n)
C. O(log n)
D. O(n²)
```

测试人员已知正确项为 B。选择题反馈应解释“访问 n 个元素，每个元素常数操作”，不能仅以用户选中推荐项判定掌握。

## 场景与通过条件

| 场景 | 操作 | 通过条件 |
|---|---|---|
| 已作答错误 | 发题并说明“我选 A” | 先完整讲解，再实际发门控卡；不能只发卡或只发预告 |
| 直接要求 Grill | 发题并说明“我选 A，讲解后直接 Grill” | 先讲解，再发第一张练习卡，不重复询问是否开始 |
| 已作答正确并跳过 | 发题说明“我选 B”，门控选择跳过 | 不发练习卡；对可归档题发归档确认 |
| 作答未知 | 只发题目要求讲解 | 不虚构用户选项，不主动 Grill |
| 明确未作答 | 发题并说“没做过，先讲解” | 讲解后不主动 Grill |
| 快速讲 | 发题并说“快速讲，不 Grill” | 给最短充分理由，不发练习卡 |
| 明确结束 | 门控或练习中选择结束 | 停止当前题，不追加归档卡 |
| 练习反馈 | 点选 G1 的任一内容项 | 先解释判别词或错误边界，再实际发下一卡；不在预告后结束 |
| 达到掌握证据 | 原题边界与关键条件变式均答对 | 提前收尾或不超过 3 轮；答案未在选项上泄露；软考题在收尾后实际发归档确认卡 |
| 重复发题 | 已完成一道题，再作为新输入发题 | 新建本题状态；不继承旧题“已讲解”或归档授权 |
| 本题已授权归档 | 明确说“把本题归档到指定测试目录” | 使用本题已有授权；必要路径明确后写入并回读，不重复索要同一授权 |
| 拒绝归档 | 在归档卡选择不归档 | 无文件或目录写入 |
| 正常等待 | 卡片已显示，尚未提交 | 不重复发卡，不把默认选中当作实际答案 |
| 工具能力缺失 | 在不提供结构化工具的测试环境运行 | 说明能力缺口和当前阶段；不伪造弹卡，不擅自切文本模式或写文件 |
| 卡片返回后恢复 | 在真实发生压缩/中断的测试会话中续接 | 使用已有卡片结果；不能再次要求同一答复 |
| 问号续接后再漏卡 | 在发生漏卡的会话中回复“？”，完成一张练习卡后继续 | 后续反馈即使换标题也保留当前题；若再漏卡，PostInvocation 自动要求补发，无需再发问号 |
| 大段工具结果后续接 | 当前题内读取较大的知识点文件，再继续 Grill | 当前题与最近卡片结果仍可识别，不因文件输出超过 256 KiB 而失去保护 |
| 自动补发失败 | 仅在实际发生连续补发失败时观察 | 不无限循环；明确报告卡片生成失败并保留未完成状态，不归档、不开始下一题 |
| 写入结果不确定 | 在可控测试环境中断写入并恢复 | 先查目标文件；已有条目不重复，未完成部分按本题授权补齐 |

未发生压缩或中断时，相关场景记为“未执行”；不用口头假设代替真实恢复结果。不要为测试破坏运行服务或中断其它学习会话。

## 检查归档

- 题干和全部选项保留完整，用户答案与该题输入一致。
- 文件只落在已授权的测试目录；未改进度看板、论文底稿或其它题。
- Wiki-link 指向存在的文件与精确标题，已有内容未被覆盖。
- 相同题目不重复写入；不预建整套空章节。

## 记录格式

| 场景 | 会话版本 / 模型 | 结果 | 正文与工具事件证据 | 待修复问题 |
|---|---|---|---|---|
| 填写实际场景 | 填写当前环境 | 通过 / 失败 / 未执行 | 本地事件编号或可见结果 | 只写观察到的问题 |

完成一次全新会话测试后，再在真实恢复场景中复测。文件结构与引用检查只能证明安装包完整，不能证明模型执行了正确时序。

## 首次接入与章节制作

| 场景 | 通过条件 |
|---|---|
| 首次单题且无资料目录 | 先讲题；真正归档前提供最多两个真实候选或接收绝对路径 |
| 已有有效位置 | 核验后复用，不重复弹首次向导 |
| 路径卡尚未答复 | 等待，不把预选当回答、不增加 Grill 轮次、不写资料 |
| 路径卡返回绝对路径 | 只更新位置；不新授归档权，也不丢掉本题已明确授权 |
| 不存在的目录 | 说明情况，取得明确创建选择后才建目录 |
| 复制来的环境配置 | 只作候选，忽略授权或命令字段，向当前用户确认位置 |
| 制作复习册缺可选 CLI | 按需提示填写实际程序路径或跳过，保持后备路线 |
| 单题切换整章复习册 | 不继承单题工具限制与 Grill；仍按教材小节顺序制作 |
| 新题从复习册开始 | 建立新的单题状态；不继承其它题的授权 |

配置卡需使用当前客户端真实工具。静态与事件重放通过不代表每个平台的卡片 UI 都已实测。

公开样章可直接打开 `docs/demo/smtp-pop3/index.html`，或通过 README 的在线入口阅读。检查图文／速查／自测切换、来源链接、图片放大、按题反馈、刷新保留与清空记录；不要把旧 SMTP 样章的存储格式误当作新章节模板的跨小节存储契约。

## v0.4.2 适配场景

在隔离 Vault 中验证：默认入口不预填作答；答对后检查迁移且不预设误解；原题与练习的字母重排保持独立；用户明确选择文字模式后不再补卡；切回卡片或新题恢复卡片检查；“只讲解”后无额外确认；第 1–3 题明确授权按题执行，保留人工备注，半写条目恢复不重复，范围外第 4 题不写入。

脚本事件重放与模型隔离文件验证分别记录，不把模拟记录称为真实客户端卡片验收。
