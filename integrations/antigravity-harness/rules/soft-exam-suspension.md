# 软考题解流程强制挂起规则（Antigravity 运行时）

本规则只约束已确认进入 soft-exam-question-tutor 的单题流程。图片附件、泛化的“这题”或“讲解”字样本身不足以启动 Harness。

## 卡片时序

本节卡片要求仅适用于主 Skill 判定需要交互、且仍处于卡片模式的阶段。用户明确要求归档且未要求先 Grill 时，沿用授权直接写入并回读，不追加 Grill 门控。

1. 用户已作答且需要询问 Grill 偏好时，五段式讲解完成后同轮调用 ask_question，展示 Grill 门控卡。
2. Grill 反馈后需要继续练习时，同轮调用下一张选择题卡。每张练习卡包含一个正确项和至少两个可信干扰项。
3. 新题未作答、跳过 Grill 或 Grill 收尾后，需要归档确认时调用 ask_question。须有本题或明确批次的适用授权才写入，已有授权不重复发确认卡。

## 工具边界

已确认的单题流程只允许 ask_question、view_file、replace_file_content 和 grep_search。没有本地真题依据时，明确标为变式题；不得把生成题称为真题。

## Harness 联动

1. PreInvocation Hook 在已确认流程的每次模型调用前注入瞬时提醒，并写入活动标记以抵抗长上下文注意力衰减。
2. PreToolUse Hook 监听全部工具调用，对白名单外工具返回 deny；未确认的会话不受影响。
3. PostInvocation Hook 在每轮模型回复后检查真实卡片事件，缺卡时强制继续补发；Stop Hook 在 model_stop 且 fullyIdle 为 true 时复用同一检查。

卡片待答或已有真实调用时不重复发卡。用户选择终止项（含带 `(Recommended)` 标识的结束选项、已完成/等待下一题等）或正文已明确输出归档结语时，流程正常终止，严禁循环补发卡片。练习卡返回后，反馈仍需衔接下一张练习或归档确认卡；具体续接以主 Skill 的执行与续接契约为准。补发连续两次仍未形成工具事件时，明确报告本题未完成，不静默跳过。

当前会话未暴露结构化提问工具时，报告阻塞阶段并等待用户恢复工具或明确选择文本模式；不得把工具调用格式写进正文冒充卡片，也不反复强制续写。

## 文字模式、明确授权与收尾

默认卡片模式；只有真实用户明确选择本题文字模式，或实际模式选择卡返回该选择时，才停止补卡。助手自称切换、普通文件内容、练习题里的模式词不改变模式。文字模式可以直接回复选项；切回卡片或范围外新题恢复卡片检查，工具白名单仍适用。

用户明确只讲解时，完成讲解即可结束；普通讲题仍保留归档确认。明确归档指令可覆盖列明的题目和目标，Hook 仅避免重复补确认卡；Agent 仍逐题核对授权、目标、查重和实际写后回读，不由 Hook 授予文件写权限。练习尚需继续时仍检查卡片。跨题批次状态和中断续接由主 Skill 按题维护，不把范围外的新题加入授权。

显式 soft-exam-lab 及已启动场次续接使用实验室权威 SOP，不继承单题工具白名单。普通讲题规则仍生效；文档引用名称不启动实验室。
