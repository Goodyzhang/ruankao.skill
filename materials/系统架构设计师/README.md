## 下载与使用

[资料 Release](https://github.com/Goodyzhang/ruankao.skill/releases/tag/materials-v1.0.0) 提供合集及教材、笔记、题库与案例、论文四个分类包；各包与合集重叠，无需重复下载。分类索引使用在线入口，下载包内可直接打开对应目录。跨类别引用指向在线文件，本类别的图片与资源随包提供。

视觉复习册不进入资料 ZIP。完整仓库中打开 `artifacts/index.html` 即可离线阅读。

如需 AI 讲题和作答工具，另下载 [v1.0.0 工具 Release](https://github.com/Goodyzhang/ruankao.skill/releases/tag/v1.0.0)。把资料放在个人资料目录，并明确告诉 Agent 位置；资料包不会运行安装程序，也不会自动覆盖已有笔记。

## 范围与来源

发布副本去除个人答案、得分、批改、错次、复习状态和会话信息；个人论文、项目底稿及相关练笔整篇排除。保留教材书目信息、题源、参考解析性质、OCR 和缺漏说明。资料内容并未逐题重新校对，参考答案与训练评分不能一概视为官方结论。
