# 汽车租赁系统：状态机图填图 + UML 动态模型 + RUP 9 工作流（高级下午）

## 题干（原题抄写）

> 【说明】某软件公司拟开发一套汽车租赁系统，科学、安全、方便地管理租赁公司各项业务。注册用户在使用系统进行车辆预约时需执行以下操作：(a) 用户登录系统 (b) 查询车辆信息 (c) 预订车辆 (d) 提取车辆 (e) 归还车辆 (f) 计算结余 (g) 查询还车时间。
>
> 【问题 1】（6 分）状态机图和活动图用于建立软件的动态模型，请分别阐述这两种图的概念和特点。
> 【问题 2】（10 分）图 1-1 给出注册用户的状态转换过程（状态机图：初始→注册用户→(1)；登录失败→终态；登录成功/(9)→(2)→(4)→(6)；登录成功/(8)→(3)→(5)→(7)→终态；(6) 斜线回连 (3)），用 (a)~(g) 补全 (1)~(7)，并给出 (8)(9) 状态转移执行动作。
> 【问题 3】（9 分）RUP 有 9 个核心工作流（6 核心过程 + 3 核心支持），用 300 字以内文字简要说明其主要作用。
>

## 考场答案与采分要点

**问题 1**：状态机图 = 描述单个对象生命周期内的状态序列、引起转移的事件及伴随动作，以状态为中心、事件驱动；活动图 = 描述活动到活动的控制流（流程图），以活动为中心、流程驱动，支持分支与并发、可泳道划分多对象。

**问题 2（⚠️ 推导版答案——材料未附官方答案）**：(1) a　(2) b　(3) d　(4) c　(5) e　(6) g　(7) f；(8) 检索并核对该用户的预订（订单）信息　(9) 读取并显示车辆信息（进入查询界面）。

**问题 3（材料官方答案）**：
- 业务建模 = 为目标组织开发构想、定义过程角色责任；
- 需求 = 描述系统该做什么并达成共识；
- 分析和设计 = 需求转设计、以体系结构设计为中心；
- 实现 = 组织代码、组件化实现、测试并集成；
- 测试 = 验证交互与集成、全程迭代测试；
- 部署 = 生成版本并分发（打包/安装/用户帮助）；
- 配置和变更管理 = 控制产物、管理版本、支持并行开发；
- 项目管理 = 平衡目标、管理风险；
- 环境 = 提供过程和工具。
