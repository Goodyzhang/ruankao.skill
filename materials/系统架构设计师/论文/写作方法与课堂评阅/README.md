# 论文写作方法与课堂评阅

这组材料介绍审题、组织论文、检查技术论证和反馈修改意见的方法。课堂案例、教学替换段和训练估分均用于说明方法，不代表资料整理者的项目经历，也不构成官方评分标准。

1. [论文写作与评阅清单](论文写作与评阅清单.md)：先对照题目要求，再核对实例、技术机制和结果。
2. [专题 3：写作方法与课堂案例分析](专题3-写作方法与课堂案例分析.md)：摘要、背景、主体、结尾及面向对象分析、架构风格、ABSD。
3. [专题 4：常见问题与课堂案例分析](专题4-常见问题与课堂案例分析.md)：偏题、空泛实例、技术边界和局部材料评阅。
4. [课堂论文模拟评阅](课堂论文模拟评阅.md)：用同一训练量表逐项检查课堂材料。

个人练笔、项目底稿、结合个人业务项目写成的押题稿及历史备份不在本目录中。论文真题见 [真题目录](../真题/)。
