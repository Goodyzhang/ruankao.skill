# 系统架构设计师高级备考调度

本 Skill 负责学习节奏、案例表达、论文素材和进度；单题讲解、Grill 和归档由 `soft-exam-question-tutor` 统一处理。

## 知识库位置

首次需要本地资料或原绑定失效时，按 [first-use.md](../soft-exam-question-tutor/references/first-use.md) 引导资料位置与所需工具；已有有效位置直接复用。默认 `个人资料/笔记/软考/` 仅为候选。纯知识讲解可先继续，读取个人进度或写入计划前再完成位置确认。

## 路由边界

| 请求 | 动作 |
|---|---|
| 讲解当前一道题、判断选项或诊断错误过程 | 交给 question-tutor |
| 今日学习、章节计划、D1/D7/D21、案例训练、论文提纲 | 本 Skill |
| 完整历史高级对话的整理导入 | `soft-exam-architect-organizer` |
| 将已学章节或指定专题制作、续写、修订为图文速查复习册 | `soft-exam-review-book`；读取其权威流程，素材只读 |

## 模式

- `explain`：围绕一个高级知识点讲解，标明综合知识、案例分析或论文中的考查位置。
- `quiz`：先给练习和作答要求；用户作答后按 question-tutor 的诊断规则反馈，不在题目首次出现时直接公布答案。
- `case`：训练“题干关键词 → 专业术语 → 权衡理由”的答题表达。
- `paper`：仅使用 `02_论文项目底稿.md` 已有项目背景与材料；缺少事实时标为待补。
- `review`：按下方 D 值日期规则，从 `01_学习进度看板.md`、当前章级错题本和知识点中列出 D1/D7/D21 动作。
- `progress`：用户明确要求时更新 `01_学习进度看板.md`，不重写既定学习总计划。

## 当前知识库结构

- 高级知识点以 `系统架构设计师-高级/知识点/NN-章名.md` 的 20 章结构为准。
- 高级错题以 `系统架构设计师-高级/错题本/NN-章名-错题.md` 为准。
- `笔记.md` 与 `03_错题与复盘模板.md` 是历史汇总或格式参考，只读查重，不向其中双写新单题。
- 精确章节和小节按 question-tutor 的 [chapter-routing.md](../soft-exam-question-tutor/references/chapter-routing.md) 与 [architecture-toc.md](../soft-exam-question-tutor/references/architecture-toc.md) 判断。

## D1/D7/D21 日期规则

1. 基准日优先取错题或学习条目中明确记录的实际完成日期；其次取对应的带日期每日记录。不要把计划日期、空白 D1 字段或 D7/D21 勾选框当作基准日。
2. 有基准日时，按自然日计算：D1 = 基准日 + 1 天，D7 = 基准日 + 7 天，D21 = 基准日 + 21 天。
3. 没有基准日时，只列为“待建立首轮复习基准日”，不声称今天到期，也不凭空补写日期。
4. 用户明确要求更新时才回写看板、错题条目或每日记录；只问“今天哪些到期”时保持只读并说明缺失依据。

## 输出要求

- 说明学习任务为什么服务于综合知识、案例或论文，并给出可执行的本轮动作。
- 案例答案必须引用题干事实，再给专业术语和权衡理由。
- 论文不得虚构项目、指标或实施结果。
