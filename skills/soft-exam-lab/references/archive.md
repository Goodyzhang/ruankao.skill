# 档案与错题收尾

显式启动本功能且提交本场练习后，保存完整档案和可靠失分点属于该场已说明的工作流。记录当前用户原始启动请求、场次和提交状态；未提交、其它场次和今后未知练习不因此取得授权。

场次目录本身即完整档案：私有题包、版本评分表、冻结答卷（文字/图稿/PNG/附件/时间）、逐点评阅、来源和离线public/report.html。归档根不会被服务整目录公开。初次路径引导需要真实选择，局部环境疑问不重置原答卷。

失分点使用现有 tutor `references/knowledge-base-contract.md` 与 `architecture-toc.md`，保持章名、公共字段顺序和精确知识链接。非选择题写“正确结论”，仍用“我的选项”保存原作答，“其它选项分析”改为“错误过程分析”，并保留完整大题及小问上下文、真实文字与图稿档案链接。共用稳定大题/小问身份；同一次attempt的多采分点合并为一条，真实不同尝试在同一题历史下追加，不改人类旧备注。记录 `soft-exam-lab:<attempt_id>:<question_id>` 去重键、引用来源和评分口径。遗漏不擅自解释成用户误解；仅有训练额外扣分时明确标签，不当成官方扣分。

Agent负责语义判断与章级选址，运行器不猜章节也不整库改写。把本场可靠遗漏/错误与非重复训练错误逐项归档；未核验点先补材料。回读目标段落和Wiki-link精确锚点，确认图片可读、原作答和旧内容保真、一次attempt只出现一次。知识点正文不自动重写。

回读后制作 data-contract 规定的 archive-receipt，包含覆盖采分点/extra原因ID、文件绝对路径与当前SHA256，然后 finalize。没有失分可用空覆盖/空文件，但仍保留完整档案。未完成评阅/待核验/缺回读不能清入口。已成功归档重复finalize不增加条目；只删除当前active指针，自有服务自动关闭，历史仍在。新开练习应为空答案，不复制上次作答。

年度整卷只归档实际计分题的可靠失分点，未选题不记为错题。论文的审题、结构和表达问题归入论文写作章节，具体技术错误按对应学科章节定位；生成的应试参考范文保留在本场报告中，不替换用户原作答或真实项目底稿。
