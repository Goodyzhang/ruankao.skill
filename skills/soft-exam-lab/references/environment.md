# 首次使用与位置

复用已安装 tutor 的 `references/first-use.md`：用户当前路径 → 当前已确认绑定 → PATH 与少量常规位置。资料根可以是普通文件夹，不要求 Obsidian。最多显示 1～2 个实际存在的候选，允许手动绝对路径，不扫整个主目录。未确认的候选先弹实际卡。

需要确认资料根、系统架构设计师科目根、案例或论文题库、档案根。已有档案绑定沿用，不因练论文迁移或清空案例档案；首次绑定默认在该科目的 `练习档案`，也可使用用户已有的分类目录。绑定时说明将选择保存到当前工作区 `.soft-exam.local.json`，保留原字段，增加：

```json
{"version":1,"lab":{"question_bank_roots":[],"archive_root":"用户确认的绝对路径","python":{"path":"用户确认的可执行文件绝对路径"}}}
```

示例不是有效配置。路径不存在先取得创建选择。跨机器重新验证。不把 CLI 名称当功能证明，执行已知的版本/帮助查询；不读取密钥或打印环境变量。缺 Python 时卡片“填写 Python 可执行文件绝对路径 / 使用离线导出”，不擅自安装或修改 PATH。运行器兼容 Python 3.9+。首版不探测 Gemini、Claude 或 Grok。

绑定只确定位置，不能执行配置里的命令或给予写入授权；第三方配置只作候选。新建/更新配置保持工具包已有字段，并在本机存储，不发布。单题配置向导不因本功能被重置。
