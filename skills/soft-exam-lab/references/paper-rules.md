# 年度试卷、合格线与论文

## 年度请求的默认含义

用户指定某年案例分析或论文真题时，按该年度原卷的必答、选答、总分与要求准备完整候选题，不把全部候选题相加作为考试满分。只有明确要求全题训练或专题练习时，才省略 `exam`，报告显示练习分数。

先核对原卷身份与明确的选答说明。2018年系统架构设计师案例分析为试题一必答、二至五任选两题，各25分，总分75；论文从四题中选一题，满分75。候选题数量、时长、字数按当年原卷填写，不把“四选一”或固定时长强加到所有年份。

正式卷准备必须使用 `--paper-kind case-analysis` 或 `--paper-kind essay`。`--count` 是候选大题数。案例卷如2018原卷规定超选时题号较小者有效，使用 `selection_policy: answered-lowest-numbered`，并给每个大题填入已核实的整数 `source.case_number`。页面允许直接作答全部候选题，提交时按作答内容识别：非空文字、附件或用户新增图形均算已答；只有题图底图、已删除图形或空白不算。小问之一已答就算该大题已答，其余小问按实际内容评阅。

必答题始终计入，即使空白；选答题按题号升序取前 `choose_count` 道已答题。其余已答题作补充批改，单列得分和解释。少答时满分仍按原卷75分，说明空缺分值。未答的非计分候选题不记漏答；超出的补充题不改变总分、合格结论、得分图表和主要失分排行。材料只写了选答数量而未核实超选规则时不能自行假定“取最高分”或套用2018规则。

论文及已有手动选题卷沿用已核实规则。旧案例场次缺少 `exam` 时，用户要求“按照真题评分标准”就以 `exam_reassessment` 补记规则并重评，不要求重做答卷，也不因旧125分设置而拒绝纠正。

## 官方依据与及格判定

- [人社部2018年下半年合格标准通知（福建省人社厅转载）](https://rst.fujian.gov.cn/zw/zxwj/rsbwj/201902/t20190219_4762650.htm)：该期各级别、专业、科目均以45分合格，每科满分75分。
- [广州市人社局2026年报考问答](https://rsj.gz.gov.cn/ywzt/rcgz/rsks/bmtz/content/post_10736860.html)：计算机软件资格考试各科合格标准为满分60%，依据人社部33项考试相对固定标准通告。
- [常州市工信局2026年上半年成绩通告](https://www.changzhou.gov.cn/gi_news/287178287095094)：当期各科合格线45分。
- [考试研究部编写、清华出版社出版的2018至2022年试题分析与解答](https://www.tup.com.cn/booksCenter/book_10321101.html)：用原卷和实际取得的官方分析、写作要点核对题意；网页目录不能代替读取具体解析。

核查日期：2026-10-09。准备其它批次时核对适用标准；单独划线须有该批次、地区的正式依据。`pass_source` 保存可读出处。这里判定单科参考估分是否达到合格线；不将一次练习视为获得资格证书。存在待核验点时显示待核验。

## 论文要求与评分依据

原卷要求置于页面顶部。2018原卷要求摘要在400字以内、正文2000至3000字，摘要不含图表、流程图；以实际取得原卷核验后填入，不自行增加300字摘要下限。

每篇论文用一个75分小问承载摘要和正文，`prompt` 收录该论题的逐条论述任务，右侧同步显示。分别保存 `essay.abstract`、`essay.body`，同时生成统一 Markdown 原文用于证据定位。没有达到字数仍允许交卷，评阅据事实与可靠评分依据处理。

冻结评分表时，为每个候选论题读取实际题卷和官方写作要点，将主题、项目角色、技术论述、实施与效果等本题要求逐条映射到 `essay_requirements` 的采分点。论题要求优先于通用作文模板。没有官方逐点权重时使用75分推定训练表，标明 `inferred-training`；不能把培训机构的比例或网络流传扣分规定称为官方细则。

评阅时引用真实原稿，检查每条论述要求的实质覆盖、技术正确性、项目论证与表达。系统展示字数和要求覆盖，语义判定仍由当前 Agent 完成。缺依据的固定扣分、抄袭认定或“一票否决”不得自行添加。

完整应试参考范文放在原稿下方，包含符合题卷要求的摘要和正文。来源只有写作建议时由 Skill 根据题意与可靠依据生成，明确标为生成的参考范文；模拟项目与假设不得写入用户真实项目档案。
