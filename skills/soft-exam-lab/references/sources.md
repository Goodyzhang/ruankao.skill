# 取材 Gate

选题顺序：已绑定本地真题库 → 历史错题中的完整案例题 → 联网补缺 → 弹卡填写题库路径或换考点。只找本次所需材料，联网补缺优先原始来源。

每题核验：完整背景、全部小问、每小问分值、必要图示、可靠解析。检查图片实际像素和 OCR，不靠文件名认定年份。回忆版显式标注；题源未确认不响应真题请求。原 PDF 图示截取保留文件与页码，原图不能用重画示意图冒充。跨小问上下文不截断。

“待补充”、无法阅读的 OCR、关键题图缺失、答案不存在均不能进入试卷。题数不足时卡片“减少数量 / 补充题库 / 更换考点”；一套三题不能暗中变成一题。

解析优先考试研究部的指定试题分析书，其次可核查的机构原始解析。出版社元数据只能证明书的身份，不能证明你已经读到其中答案；实际页码或解析内容仍需获取。记录出处级别、版本、页码/URL、核验时间和冲突。清华出版社线索见 [research.md](research.md)。

原图本地保存、题页支持放大。公开题包只放考试身份与必要题目；答案、完整采分表、材料私人绝对路径留在服务之外。需要分享题目时另核实权限，作答环境的本机存储不等于公开发布。

可靠答案 + 小问总分已有、缺逐点分值：Agent 分拆独立可核验事实，分值加总等于小问，注明 `inferred-training`，不声称官方采分表。存在实质争议先补资料或换题。已提交后发现争议，转待核验。

题库整理入口导出的 web-bank 可用于普通案例练习，但不满足“历年真题”要求。先检查完整题目、原图和核验回执，公开包只接收原图；解析、答案标注图与评分表留在私有目录。网站题号不能替代考试身份。

年度案例与论文整卷按 paper-rules.md 核实原卷选答规则和满分。论文通常没有唯一标准答案：原卷明确论述要求与可靠的官方写作要点可作为评分依据，不能因缺少一篇标准范文就补造官方答案。来源为概括建议时，评阅阶段应根据可靠依据生成完整应试参考答案；生成的模拟项目、假设与来源需明确标注。
