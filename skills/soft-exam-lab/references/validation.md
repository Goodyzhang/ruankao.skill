# 开发验收

在隔离资料根进行，不能把验收假作答写入真实错题本。运行器不语义阅卷；固定语义答卷由当前Agent逐点检查，独立开发验证不改变单代理生产阅卷。

必要行为：显式入口和续接、缺方向/数量真实卡片、专题三题、真题身份不明、缺题图/解析、题数不足；输入Markdown/公式、题图放大、画图与PNG、暂停/刷新/限时；未落盘点已提交、磁盘失败、重复提交、跨场串答、提交后修改、Agent中断续批；空白、遗漏、同义、模糊、术语正但机制错、反向箭头、额外错误、重复同因、争议解析；双分数与图表、证据、离线档案、错题去重、保留历史与下场空答案。

先运行新功能定向测试，再运行受影响的安装/Harness/包校验。Python测试：公开仓库 tests/test_soft_exam_lab.py；路由测试：tests/test_soft_exam_review_routing.py。格式校验用skill-creator quick_validate，不能替代行为测试。前端维护者npm ci/build；用户不需要npm。

优先内建浏览器完成实际编辑、保存、刷新、绘图、交卷、报告；桌面和平板宽度分别检查。固定答卷记录实际逐点评阅而非关键词匹配。没有实测的Agent客户端、平台、触控、Windows/PowerShell和恢复能力单列，不用文件存在推断成功。

年度试卷定向测试另见公开仓库 `tests/test_soft_exam_exam.py`：必答与选答数量、选择后保留草稿、75分分母、45分及格边界、待核验不判失败、未选题不计入失分、选题冻结与离线导入。论文覆盖一篇计分、摘要正文原文一致、原卷要求到采分点映射、完整范文字数；案例缺少完整参考答案时不得生成宣称完成的报告。

浏览器检查右侧当前小问、卷面要求与选题控件、论文摘要正文、完整参考答案的位置、单科及格判定和失分排行。测试使用隔离自编题，不能改写用户已完成的答卷和历史分数。

三色批注验证：公开仓库 `tests/test_soft_exam_annotations.py` 检查精确证据、风险提示不扣分与原答卷保真；`tests/test_lab_annotations.mjs` 检查重复词句、Unicode 偏移、Markdown 列表/表格/代码/公式与长论文。前端依赖装好后使用 `node --test --test-concurrency=1 tests/test_lab_annotations.mjs`，临时构建目录可通过 `SOFT_EXAM_FRONTEND_ROOT` 指定。实际浏览器检查右侧引文点击定位、左侧激活边框、原始 Markdown 展开，以及桌面和窄屏。用户明确授权的实际答卷可复制到隔离展示场景截图，不改原场次；其它示例标明自编。

参考答案一致性：`tests/test_soft_exam_reference_consistency.py` 复现 evaluation 覆盖评分表并生成相反答案的旧行为；检验来源分叉、correct 不在正文、缺少/重复/跨题核对点、未解决冲突均被阻止，拒绝时已有报告不变。检验修订后原答卷保真、展示来源由评分表生成、争议只输出 pending。年度试卷测试继续覆盖只核对计分题和完整论文范文。真实报告逐题语义审核单列记录，不以程序通过声称自动理解答案。
