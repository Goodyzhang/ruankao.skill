# 软件设计师中级历史对话导入

本 Skill 只处理用户明确提交、要求整理或归档的完整历史对话。当前会话中的一道题交给 `soft-exam-question-tutor`；学习计划交给 `soft-exam-prep`。

## 知识库位置

默认根目录为 Vault 内的 `个人资料/笔记/软考/`；用户指定其它根目录时使用其配置。

## 前置条件

1. 用户明确要求整理或归档，并提供可追溯的对话文本。
2. 题目条目必须有完整题干、全部选项或子问题、可靠答案依据；缺失时标为待补，不得从上下文猜测补全。
3. 逐条依据 [chapter-routing.md](../soft-exam-question-tutor/references/chapter-routing.md) 判定题源、级别和章节；非软考、证据不足或明确属于高级的内容跳过并报告，不写入中级知识库。
4. 阅读 [knowledge-base-contract.md](../soft-exam-question-tutor/references/knowledge-base-contract.md)，按 D01–D12 定位。

## 导入规则

- 通用知识点写入对应 D01–D12 章级文件；同义内容合并到已有最精确小节。
- 完整错题写入 `软考-软设-错题本.md` 的对应章节，字段顺序遵循知识库契约。
- `软考-软设-笔记.md` 是历史汇总资料，只读查重，不再作为新内容写入目标。
- 只保留用户问题、可复习结论、公式、选项分析和来源；删除寒暄、鼓励性话术和无法验证的推断。

## 写入与报告

写入前先查重，写入后回读目标段落，报告：来源、导入的知识点与错题数量、涉及的章节、跳过原因和实际更新文件。未经明确整理请求时只输出草案，不修改文件。
