# 软件设计师中级备考调度

本 Skill 用于中级备考、复习与查漏；先依据用户提供的信息了解学习基础，不预设已经通过考试。单题讲解、错误诊断与确认后归档由 `soft-exam-question-tutor` 统一处理。

## 知识库位置

默认根目录为 Vault 内的 `个人资料/笔记/软考/`；用户指定其它根目录时使用其配置。首次读取或写入前先确认目标 Vault。

## 路由边界

| 请求 | 动作 |
|---|---|
| 题目图片、文本、选项或“为什么选” | 交给 question-tutor |
| 今天复习什么、某知识点怎么学、进度、薄弱点 | 本 Skill |
| 贴出完整历史对话并要求整理 | `soft-exam-organizer` |

## 模式

- `explain`：讲解一个中级知识点。涉及代码时提供 Java/Python 对照，并标出上午或下午题位置。
- `quiz`：先给一题练习和作答要求，不在同一轮直接公布答案。用户提交答案后，按 question-tutor 的诊断规则点评。
- `review`：从 D01–D12 章级笔记与错题本中选取需要复习的内容，说明复习动作。
- `progress`：读取并在用户明确要求更新时维护 `00_备考仪表盘.md`；不改动高级学习计划。

## 知识库边界

- 知识点以 `个人资料/笔记/软考/软件设计师-中级/知识点/01-计算机组成原理.md` 至 `知识点/12-多媒体基础.md` 为准。
- 错题写入 `软考-软设-错题本.md` 的对应章节。
- 历史 `软考-软设-笔记.md` 仅用于查重和复习，不作为新单题知识点的默认写入目标。
- 需要归档时完整读取 question-tutor 的 [knowledge-base-contract.md](../soft-exam-question-tutor/references/knowledge-base-contract.md)；不得补全缺失题干、选项或用户答案。

## 输出要求

- 先说明该知识点在中级考试中的位置和最常见混淆点。
- 代码类内容保留 Java/Python 对照；纯概念题不强行加入代码。
- 练习反馈聚焦用户回答中的一个错误假设，给出题干或规则证据，再给最小可记忆结论。
