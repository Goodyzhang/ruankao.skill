# 软考单题讲解、诊断与归档

本 Skill 只处理一道当前题目：输入完整性、分级、讲解、可选 Grill 与确认后归档。学习计划和整段历史对话整理应由工作区中的其它专用流程处理。

## 工作流

### 0. 输入 Gate

1. 获取完整题干、全部选项或子问题、图表、公式、单位、限定词和题源标记；多张图按题目顺序合并。
2. 图片无法读取时，使用会话中的 OCR 文本、可访问附件或当前可用视觉/OCR 能力；仍不能可靠取得内容时，请用户补充清晰截图或文本。
3. 裁切、遮挡、模糊或关键字符不确定时标为 `[不清晰]`。只要会改变答案，就停止并请求补充；不得猜题、补选项或根据答案反推题干。
4. 同一材料含多道独立题时，先编号。用户未指定题目时，用一张结构化选择卡让用户选择本轮先处理哪一题；卡片最多列 3 个选项，更多题目使用“输入其他题号”或按题号分页。批量处理时，每题分别维护作答状态、Grill 和归档记录，并在写入前取得该题自己的归档确认。

材料完整后直接继续，不为形式确认而中断。

### 1. 题源与分级

读取 [chapter-routing.md](references/chapter-routing.md)，先输出：

```text
题目归属：软考明确 / 软考知识域相关但题源未确认 / 非软考或证据不足
级别：软件设计师-中级 / 系统架构设计师-高级 / 两者共有（归档前待确认）
依据：截图来源标记、题型、考查深度或知识域；置信度：高 / 中 / 低
```

- 题目主题相近不等于软考真题；没有可靠来源时如实标为“软考知识域相关但题源未确认”。
- 两级共有知识点不能只凭主题二选一。可以先讲通用原理，归档前再让用户选定级别。
- 非软考题仍可讲解，但不归档到软考知识库。

### 2. 讲题

默认按以下骨架输出。用户要求简答时可以压缩，但答案必须有最短充分理由。

```markdown
## 题目复原

## 考点与判别词

## 解题链

## 答案与选项分析

## 迁移提示
```

- 说明决定答案的题干词、边界条件或计算结果。
- 选择题逐项说明；计算题定位概念、公式或计算错误发生的位置。
- 标题、表格、列表和代码块之间保留合理空行；标题层级不跳级。
- `quick` 场景可以给出变式答案；标准讲解和 Grill 场景的变式题先等用户作答。

### 3. 决定是否进入 Grill

输入阶段先记录 `attempt_input`：`unknown`（未说明）、`not_attempted`（明确未作答）或 `attempted`（给出了答案或过程）。完成可靠解题后，才把 `attempted` 解析为 `correct` 或 `wrong`。

| 最终状态 | 讲解后的动作 |
|---|---|
| `unknown` / `not_attempted` | 不主动弹 Grill，进入归档确认或结束 |
| `correct` / `wrong` | 用结构化卡片询问是否 Grill |

- 用户明确要求 Grill 或深度追问，且已有题目、作答上下文和可靠答案时，可直接进入 Grill。
- 用户明确说“不 Grill”或“快速讲”时跳过 Grill。
- 使用当前运行时提供的结构化提问能力。Codex 可用 `request_user_input` 时使用它；只有工具清单确实提供 `AskUserQuestion` 时才使用该名称。
- 卡片只承载一个简洁问题和 2–3 个行动选项，例如“我来解释 / 给一个提示 / 跳过”。没有理由文本不得判为通过。

### 4. Grill：按诊断状态追问

进入 Grill 前，完整读取 [grill-diagnostic-contract.md](references/grill-diagnostic-contract.md)。

追问围绕一个可验证的错误假设展开。每轮根据用户刚刚给出的理由决定下一问：

- 缺少关键判别词：追问题干证据或给一条最小提示。
- 混淆相邻概念：只比较这一对概念的边界。
- 理由正确：用一个只改变判别词的反事实检验迁移。
- 用户跳过、换题或连续两次只要提示：结束或回到简明讲解。

最多进行 3 个有实际回答的诊断回合；达到掌握证据时提前收尾。不得因点选“通过”或凑满三问而宣布掌握。

### 5. 归档

只有题目归属为“软考明确”或“软考知识域相关但题源未确认”时，才询问是否归档。归属为“非软考或证据不足”时，讲解后结束。

单题确认归档后：

1. 完整读取 [knowledge-base-contract.md](references/knowledge-base-contract.md)。
2. 两级共有题先确认归档级别。
3. 只写本题相关的章级知识点和错题目标；不迁移目录、不重写既有笔记。
4. 写入后回读目标段落，核对题干、选项、答案、用户作答、Wiki-link 与标题层级。

批量题不得用一次“归档”确认授权整批写入。每题在进入写入步骤前都要得到独立确认；未确认的题保持只读。

## 边界

- 归档确认只授权本题相关内容；未经明确同意不得创建或修改知识库文件。
- 没有可靠答案依据时说明证据不足并停止归档。
- 不依赖或分发教材 PDF、题库、答案语料、用户截图或个人笔记。
