# 软考题目讲解与知识库归档

把本 Skill 作为图片与文本讲题的统一入口。优先执行输入校验、分级、讲解和写入确认。若工作区还能发现 `soft-exam-prep` 或 `soft-exam-architect-prep`，可在分级后按需读取；缺少这些可选 Skill 时继续执行，不中断讲题。

## 工作流

### 0. 校验输入

1. 检查是否取得图片像素或完整题目文本。
2. 能读取图片时，按版面顺序识别题干、全部选项、所有子问题、图表、公式、单位、限定词和来源标记。多张图按题目顺序合并。
3. 当前模型不能直接读取图片时，尝试使用会话中已有 OCR 文本、可访问附件或当前可用的视觉/OCR 工具。
4. 仍无法取得题目时，明确说明无法读取图片，请用户切换多模态模型、重新上传清晰完整截图，或粘贴题目文本。不得声称已经看见图片。
5. 出现裁切、遮挡、模糊或关键字符不确定时，用 `[不清晰]` 标出；只要会影响答案，就先请用户补充，不猜题、不补选项、不根据答案反推题干。

材料完整且识别可靠时直接继续。

### 1. 判定题目与分级

完整读取 [chapter-routing.md](references/chapter-routing.md)，输出：

```text
题目归属：软考明确 / 软考知识域相关但题源未确认 / 非软考或证据不足
级别：软件设计师-中级 / 系统架构设计师-高级 / 两者共有（归档前待确认）
依据：截图来源标记、题型、考查深度或知识域；置信度：高 / 中 / 低
```

- 区分“题源”与“知识域”。没有试卷名称、年份或可靠来源时，使用“软考知识域相关但题源未确认”。
- 软件工程、数据库、网络、安全、操作系统、UML 等共有内容不能只凭主题二选一。
- 判为非软考时仍按讲题链解释，但不主动写入软考知识库。

### 2. 按统一骨架讲题

默认使用以下结构；用户明确要求简答时可以压缩，但保留必要推理。

```markdown
## 题目复原
（简洁复述题干、选项与关键图表信息；标明不确定字符）

## 考点定位
- 一句话说明考查的原理、公式或规律，先不报答案。
- 说明它在知识体系中的位置。
- 若属于软考，标注考试级别、常见题型和重要度。

## 逻辑链
1. 为什么先做这一步。
2. 中间推导及其概念、数学或工程含义。
3. 单位、符号、边界条件和结论。

## 答案
（在推导后给出结论及最短充分理由）

## 选项分析 / 错误诊断
（选择题逐项分析；计算题结合用户过程诊断概念错、公式错或计算错）

## 通用规律与易错点
（提炼可迁移规律、识别线索和典型陷阱）

## 变式题
（默认给一道同考点变式题；答案放在可折叠的 details 块中）
```

讲解时遵守：

- 每一步说明原因，避免只列公式或背答案。
- 多种解法只精讲最本质的一种，其余方法点到为止。
- 选择题覆盖每个选项；某选项无法辨认时回到输入校验。
- 代码题按对应考试的常见语言与题型习惯讲解；公式使用 LaTeX。
- 用户提供错误过程时，指出错误发生的位置和根因，不只说“算错了”。
- 无法可靠验证答案时，说明证据不足，不把推测写成正确答案。

### 3. 询问是否归档

完整讲解后只问一次：

> 是否需要把这道题整理进软考知识库？如果需要且你做过这道题，请同时告诉我你的选项；未作答可回复“未作答”。

不要在用户回答前创建或修改知识库文件。用户拒绝、跳过或未回答时，到此结束。

### 4. 用户确认后归档

1. 完整读取 [knowledge-base-contract.md](references/knowledge-base-contract.md)。
2. 若级别仍为“两者共有”，先让用户确认归入中级还是高级；确认前不写文件。
3. 根据 [chapter-routing.md](references/chapter-routing.md) 定位章级目标。
4. 需要精确小节时，依次采用已有知识点文件标题、用户提供的合法教材目录或可靠资料。无法验证小节号时使用契约中的“未定位到教材小节”，不得虚构 `N.x` 或 `N.x.x`。
5. 检查目标知识点与错题是否已存在，避免重复；只写本题相关目标，不迁移或重写整个知识库。
6. 先写或补充知识点标题，再写错题条目，使知识点链接落盘时即可跳转。
7. 依次写入：原题抄写、正确选项、简析、我的选项、其它选项分析、知识点链接。不得虚构用户选项、题目来源、年份、答案依据或个人错因。
8. 图示只有在语义无损时才改写为 Mermaid；公式使用 LaTeX。无法无损重建的图保留图片引用或文字说明。
9. 写后回读目标段落，验证题干、选项、答案、链接锚点、标题层级、frontmatter 日期和插入位置；报告修改的文件。

## 边界

- 知识库默认根目录为 `个人资料/笔记/软考/`；工作区指令或用户显式指定的 Vault 相对目录优先。
- 归档确认只授权本题相关的知识点与错题写入。
- 保留已有 frontmatter、人工内容、Wiki-link、排序和复习状态；禁止覆盖整份文件。
- 不依赖或分发教材 PDF、题库与答案语料。用户资料不可访问时，使用章级路由并诚实降低定位精度。
- 不使用设备绝对路径，不把不确定结论归档成正确答案。
