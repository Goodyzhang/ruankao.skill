# 软考单题讲解、诊断与归档

以一道当前题目为处理单元，完成题目复原、分级、讲解、可选 Grill 与授权后的归档。用户明确要求批量处理时逐题完成，分别维护作答、练习和归档状态。学习计划和整段历史对话整理不适用本 Skill。

## 交互与资料

- 优先使用当前运行时提供且允许用于当前模式和用途的结构化提问工具。工具不存在、用途或字段约束不适合时，直接在聊天中提问；选择题列出内容选项，等待用户回复字母。不为展示卡片切换模式，也不把预选项当成实际回答。
- 只读取当前任务需要的参考文档；已读取且仍在上下文中的内容直接复用。普通讲题不加载 Grill 或知识库写入规则。

## 工作流

### 0. 输入 Gate

1. 获取完整题干、全部选项或子问题、图表、公式、单位、限定词和题源标记；多张图按题目顺序合并。
2. 图片无法读取时，使用会话中的 OCR 文本、可访问附件或当前可用视觉/OCR 能力；仍不能可靠取得内容时，请用户补充清晰截图或文本。
3. 裁切、遮挡、模糊或关键字符不确定时标为 `[不清晰]`。只要会改变答案，就停止并请求补充；不得猜题、补选项或根据答案反推题干。
4. 同一材料含多道独立题时，先编号。用户已指定题号或批量范围时按该范围处理；否则询问本轮先处理哪题，选项数量按运行时能力适配。

材料完整后直接继续，不为形式确认而中断。

### 1. 题源与分级

按“明确考试来源 → 题型结构 → 考查角度与深度 → 单个关键词”的证据强度判断，简要说明：

```text
题目归属：软考明确 / 软考知识域相关但题源未确认 / 非软考或证据不足
级别：软件设计师-中级 / 系统架构设计师-高级 / 两者共有（归档前待确认）
依据：截图来源标记、题型、考查深度或知识域；置信度：高 / 中 / 低
```

- 题目主题相近不等于软考真题；没有可靠来源时如实标为“软考知识域相关但题源未确认”。
- 计算机系统、网络、数据库、软件工程等可能是两级共有内容；证据不足时保留“两者共有”，先讲通用原理。需要进一步区分考查角度时，读取 [question-classification.md](references/question-classification.md)。
- 仅在用户要求章节定位或需要归档路由时，读取 [chapter-routing.md](references/chapter-routing.md) 中对应级别的章节表。
- 非软考题仍可讲解，但不归档到软考知识库。

### 2. 讲题

默认按以下骨架输出。用户要求简答时可以压缩，但答案必须有最短充分理由。

```markdown
## 题目复原

## 考点与判别词

## 解题链

## 答案与选项分析

## 迁移提示
```

- 说明决定答案的题干词、边界条件或计算结果。
- 选择题逐项说明；计算题定位概念、公式或计算错误发生的位置。
- 标题、表格、列表和代码块之间保留合理空行；标题层级不跳级。
- `quick` 场景可以给出变式答案；标准讲解中的练习题先等用户作答。用户明确要求先练习时，先可靠解题但暂不公布答案，按下面的入口进入 Grill。

### 3. 决定是否进入 Grill

输入阶段先记录 `attempt_input`：`unknown`（未说明）、`not_attempted`（明确未作答）或 `attempted`（给出了答案或过程）。完成可靠解题后，才把 `attempted` 解析为 `correct` 或 `wrong`。

| 最终状态 | 讲解后的动作 |
|---|---|
| `unknown` / `not_attempted` | 不主动发起 Grill，完成讲解后按用户请求归档或结束 |
| `correct` / `wrong` | 可询问是否 Grill；已有明确选择时直接遵循 |

- 用户明确要求 Grill 或深度追问，且已有题目、作答上下文和可靠答案时，可直接进入 Grill。
- 用户明确说“不 Grill”或“快速讲”时跳过 Grill。
- 需要询问时提供“开始 Grill / 只看解析 / 结束”，不要求填写理由，也不在提问中公布尚未揭示的答案。

### 4. Grill：按诊断状态追问

确定进入 Grill 后，读取 [grill-diagnostic-contract.md](references/grill-diagnostic-contract.md)。由该契约统一规定诊断状态、选项数量、反馈和结束条件；需要组织题目与干扰项时，再读取其引用的出题指南。

目标是验证候选错因或检验已答对知识的迁移，不把用户的一次选择直接当成已证实的错因。

### 5. 归档

只有“软考明确”或“软考知识域相关但题源未确认”的题目可归档。用户只要求讲题或明确不归档时，讲解完成即结束；归属为“非软考或证据不足”时说明不适用软考归档。

用户明确授权题目范围和目标后，读取 [knowledge-base-contract.md](references/knowledge-base-contract.md)，完成范围内的写入与验证，并报告各题结果。已确认的目标或能从现有 Vault 唯一识别的目标可以复用；两级共有题沿用用户指定的归档级别，尚未指定时才询问。

明确的批量授权（如“把第 1–3 题归档到已确认目录”）覆盖这些题，不再逐题索取相同确认。仅当范围含糊、目标无法确定、出现未授权的覆盖或冲突时，澄清相关部分；其余已授权题可继续。单题授权不得扩大成整批授权。

## 边界

- 归档授权只覆盖指定题目相关内容；未经明确同意不得创建或修改知识库文件，不迁移目录、不重写既有笔记。用户在会话中的明确范围与选择优先于本 Skill 的默认流程。
- 没有可靠答案依据时说明证据不足并停止归档。
- 不依赖或分发教材 PDF、题库、答案语料、用户截图或个人笔记。
