# Grill 通用出题与干扰项设计

## 何时读取

进入 Grill 并需要组织原题辨析或变式题时读取。普通讲题、题源分级和章节定位不需要本文件。诊断状态、选项数量、反馈与结束条件统一使用 [grill-diagnostic-contract.md](grill-diagnostic-contract.md)，不在此另设规则。

## 出题依据

先明确主考点、考查维度、题干判别词和当前要检验的概念边界。错因未知时围绕主考点辨析；有候选错因时设计可验证或推翻它的题目；已答对且未观察到误解时设计关键条件迁移题。

保留易混概念、正确答案依据，以及实际读取的题源文件和题号。缺少真题或用户理由时如实保留缺口，不为填满字段而编造。

## 真题检索

在用户提供或经授权可访问的真题库中，用主考点、核心术语和判别词检索，读取相关题干、选项与答案依据，用于校准考法或设计变式。

只检索已知可访问的资料，不把找到同考点真题设为继续练习的前提。资料不可访问或未找到可核验同考点真题时，如实说明具体缺口；继续基于可靠原理生成并标注“变式题”，不得伪称真题，也不把未检索说成“检索无结果”。

## 选择题生成

### 优先级

1. 原题选项完整且能检验当前概念边界：复用原题选项。
2. 已读取的同考点真题更合适：使用其考法和选项；改写后标为变式。
3. 需要检验迁移或现有题目不合适时：生成只改变关键条件的变式题。

### 正确项

正确项必须直接回答当前考查维度，例如：

- 定义题：正确的定义或意图。
- 角色题：正确角色或类图位置。
- 条件题：满足题干约束的条件。
- 流程题：正确步骤或先后关系。
- 计算题：正确公式、单位或结果。

### 可信干扰项

干扰项优先来自用户实际误选的概念、同一知识域的相邻概念，或方向、范围、先后、边界、单位等题型陷阱。每项只错在一个真实易混点，不使用无关、荒谬或重复内容，也不将候选错因陈述成用户已经承认的理由。

| 考查维度 | 正确项 | 干扰项素材 |
|---|---|---|
| 定义与特点 | 正确定义 | 相近模式的意图、表面相似但范围不同的定义 |
| 角色映射 | 正确角色 | 用户误选角色、同一模式的相邻角色 |
| 条件边界 | 满足约束的条件 | 忽略边界、扩大或缩小适用范围 |
| 流程顺序 | 正确下一步 | 提前执行、遗漏前置条件 |
| 计算公式 | 正确公式与结果 | 单位错、边界错、常见公式混淆 |
| 模式辨析 | 正确模式 | 最相近设计模式的典型意图 |

## 专项指引

专项指引只提供某类题的术语、真题锚点和干扰项素材。只有当前 Skill 包确实提供对应文件，且题目命中其适用条件时才读取；没有专项文件时继续使用通用规则。
