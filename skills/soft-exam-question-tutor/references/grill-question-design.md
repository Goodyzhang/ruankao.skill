# Grill 通用出题与干扰项设计

## 目标

任何错题都按同一链路生成 Grill，不把某一道题或某一个模式写成核心流程：

~~~text
用户错选
→ 主考点
→ 题干判别词
→ 最近错误假设
→ 同考点真题
→ 正确项 + 两个可信干扰项
→ 根据点选继续辨析
~~~

## 每题状态

进入第一张练习卡前，写清：

| 字段 | 含义 |
|---|---|
| 主考点 | 本题真正考查的定义、角色、条件、规则、过程或计算关系 |
| 考查维度 | 定义与特点 / 角色映射 / 条件边界 / 流程顺序 / 公式计算 / 模式辨析 |
| 题干判别词 | 直接决定答案的词、图示、数字、关系或约束 |
| 用户错因 | 用户选项具体混淆了什么，不用泛化的“没掌握”代替 |
| 相近真题 | 已读取的同考点真题文件和题号 |
| 易混集合 | 最接近的两个错误概念、规则或模式 |

## 真题检索

1. 用主考点、核心术语和题干判别词在本地真题库检索。
2. 读取至少一条含题干、选项和答案依据的同考点真题。
3. 真题可用于复用原选项、校准考法或设计变式。
4. 没有可核验真题时，明确说明“本地未找到相近真题”；后续题只称为变式题。

## 选择题生成

### 优先级

1. 原题选项完整且正好检验当前错因：直接复用原题选项。
2. 相近真题的选项更能检验主考点：复用或压缩为当前运行时支持的选项数。
3. 两者都不够时生成变式题。

### 正确项

正确项必须直接回答当前考查维度，例如：

- 定义题：正确的定义或意图。
- 角色题：正确角色或类图位置。
- 条件题：满足题干约束的条件。
- 流程题：正确步骤或先后关系。
- 计算题：正确公式、单位或结果。

在用户点选前，不标记正确项，不在问题中透露答案代号。

### 可信干扰项

每个干扰项只错在一个真实易混点，优先来自：

1. 用户原先选错的概念或步骤。
2. 同一知识域中最近的相邻概念。
3. 同一题型的典型陷阱，例如方向、范围、先后、边界、单位或角色树。

不要使用无关概念、明显荒谬的说法或重复选项。

## 常用题型配方

| 考查维度 | 正确项 | 两个干扰项 |
|---|---|---|
| 定义与特点 | 正确定义 | 相近模式的意图、表面相似但范围不同的定义 |
| 角色映射 | 正确角色 | 用户误选角色、同一模式的相邻角色 |
| 条件边界 | 满足约束的条件 | 忽略边界、扩大或缩小适用范围 |
| 流程顺序 | 正确下一步 | 提前执行、遗漏前置条件 |
| 计算公式 | 正确公式与结果 | 单位错、边界错、常见公式混淆 |
| 模式辨析 | 正确模式 | 两个最相近设计模式的典型意图 |

## 点选后的下一题

- 点中正确项：指出题干判别词。若需要迁移，改变一个关键条件再出一张选择题。
- 点中干扰项：指出该项只错在哪个边界，再针对同一边界出一张选择题。
- 两次都选对：收尾，不为凑题继续出题。

## 专项指引

专项指引只提供某类题的术语、真题锚点和干扰项素材，不改变上述核心流程。只有当前 Skill 包确实提供了对应文件，且当前题命中其适用条件时才读取。

新增专项时，先复用本文件的状态、真题检索和选项规则。
