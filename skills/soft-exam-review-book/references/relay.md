# 顺序接力、增量更新与验收

## 一份可继续的制作记录

章节下 `制作/续接记录.md` 保存以下实际信息即可，不要求复杂数据库：

- 考试/教材版本、章与节范围、用户最新重点及声线/角色偏好。
- 每节状态：未开始、取材、教学设计、写作、视觉、装配、待复核、完成；当前正在处理的知识组与下一动作。
- 已采用正文与资产路径、素材覆盖表、来源缺口、真实错误计数依据。
- 尚未解决的事实/图像/界面问题及各项实际验收证据；图像记录按 [分镜与审图](visuals.md) 关联两轮提示词改稿、tutor 反馈、最终提示词与实际审图结果。
- 按 [协作授权与交接范围](collaboration.md#任务授权与交接范围) 保存真实用户授权来源、已授权角色／材料范围、已发送与未发送的交接及实际审批结果。记录只帮助回溯授权，不能代替真实用户请求。
- 最近修改涉及哪些文章、题目版本和引用关系。
- 按 [环境发现](environment.md) 保存本作品的已确认资料/输出位置、CLI 绑定与跳过选择，以及尚未回答的配置卡；这些本机信息不回写共享 Skill。续接时只重验失效项。

进入会话先回读记录，再读当前产物确认。中断在“已有正文、图片待完成”时应接着生图，不能清空目录重新写；文件存在但记录称已完成仍须看验收证据。只有当前节通过内容及必要可用性复核，才推进下一节。

默认整章末统一交用户审阅。网络补知识、修图、CLI 后备等常规选择自主完成；核心结论冲突暂缓相关部分并说明。不能把尚未完成的节记为完成来维持进度。

## Goal 中的协作续接

Goal 自动续接仍沿用同一任务的有效用户授权；换小节或换图不重置已约定的教学方法交接范围。恢复时先区分“等待必要授权”“误发同范围重复卡”“调用被拒绝但未发送”和“已发送且取得响应”，按实际状态续接，不把拒绝当成发送完成。任务目的、材料或接收服务超出原范围时才核对新增授权。

为用户起草新的 Goal prompt 时，将协作范围写进用户可审阅的任务正文，例如：

> 本 Goal 按 soft-exam-review-book 的已约定协作流程制作指定章节。允许通过本任务确认的 agy／Gemini 和 Claude Code 后备发送检查后不含私人内容的 tutor／Grill 通用教学方法（需要时可全文）、本轮生图提示词、公开知识、自编场景和待编辑稿件，用于写作及生图前复核；不发送原教材或私人知识库全文、聊天记录、业务资料和凭据。同范围调用及续接不重复询问，实际工具审批仍遵守当前规则。

只有用户实际提交或明确接受该范围才构成授权；模板存在于 Skill 不代表已同意。用户已直接给出等效授权时沿用其请求，无需让用户重新抄写模板。

## 增量修改

找到新错题/用户指定内容对应的知识组，检查其段落、图片、速查、自测和跨节引用。只更新受到影响的部分。原始笔记不回写，新用户指令写入制作记录。

先区分事实错误、表达形式欠缺、历史流程证据缺失与尚未实测。新规则不自动使旧内容失效；正确关系图需要补计算讲解时，可以加伴页。历史审核用了哪个代理就记录哪个代理，不能补写成 Gemini 已审。审计误判被完整条件推翻时，撤回该条建议并保留更正理由，随后按修正后的范围工作。

题目稳定身份与内容版本见 [阅读界面](reader.md)。修改前保存受影响题目的身份、版本、题干、选项与正答，用于判断兼容性。仅正文、图像或解析润色时保留题目版本与答案；题干、选项、正答变动只使该题旧版本结果失效；复用题在不同节可有独立进度。不要把 ID 当作位置序号，改目录不能重编号所有题。

## 完成前的三次阅读

1. **只读正文**：新概念是否解决当前问题，推理缺没缺一步，反例条件是否真实改变结论？
2. **只看图和图注**：能否复述主线，有无方向/文字/计算错误？
3. **合读与练习**：知识覆盖是否完整，图文有无冲突，自测能否区分误解，速查能否迅速定位？

复杂内容让独立代理看真实材料与成品，不提供预设“应通过”的结论。静态检查、CLI成功、图片数量、字数都不能代替这三次阅读。

审阅后若正文或图像又有修改，记录被审版本与最终文件的对应关系，并复核受影响部分；图像按 visuals 要求整图回看。可用文件哈希或明确版本标识，核对最终页面实际引用了已验收资产，不能把旧图的审阅结论当作新图已经验收。

## 文件与页面检查

先用 `scripts/check_book.py`（如已随包提供）检查本地链接、锚点、重复 ID、题目身份与运行时资源；编写与修改时优先在内建浏览器查看真实页面，验收时用它验证章节目录、跨页返回、图文/速查/自测、图片放大和 Esc、错误/正确反馈、刷新保留、单题改版、重置与存储受限提示。沿用当前任务已有的有效访问授权，不为每次预览重复确认；内建浏览器确实不可用时，使用当时获准的其它浏览器并说明原因。

切换标签或锚点后，读取当前 URL、选中状态与可见内容，确认界面已经响应再断言。单次立即读取的旧状态或定位超时不足以判定页面错误；先重新观察，再定位需要复现的问题。

检查桌面和平板尺寸、长中文和公式、打印时有无截断。浏览器策略拒绝某地址时遵守限制，说明具体原因；需要新增访问授权时依当前工具机制处理，不能用另一个工具绕过拒绝。获准前记录未实测项。没有实际导出 PDF 就不声称打印分页已验收。测试在隔离记录或已确认空白题中进行，先记录原状态、结束后只恢复本次测试项；有用户作答时不点击“重做本节”或清空整库。

交付报告区别：内容通过、图像通过、静态通过、浏览器实测/未测、整节/专题/整章范围。读者界面只显示必要范围和来源，工具日志留在制作目录。

## Skill 自身的演练

新增/修改 Skill 后做格式检查与真实任务前向验证。给独立代理一个新任务、Skill 和最低必要原料，不喂预设结论；让其产出教学方案，再检查是否按事实与用户目标决策。综合布线分类适合端到端小试，流水线适合检验计算条件和步骤解释，已认可 SMTP 样章适合兼容性回读。测试材料与正式已认可作品分开保存。
