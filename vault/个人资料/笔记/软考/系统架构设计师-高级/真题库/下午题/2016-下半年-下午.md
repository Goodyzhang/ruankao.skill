## 案例一

### 阅读下列说明，回答问题 1 至问题 4

某软件公司欲开发一个网络投诉管理系统，以简化并统一处理来自用户的各类投诉。系统通过接收用户发送的投诉内容，对投诉内容进行解析过滤后，根据投诉类型分发到相应的职能部门处理，最后对处理结果进行归档、统计分析和展现。

系统主要处理流程如下：

(1) 投诉信息发送。用户通过 Web、短信、微信等多媒体渠道发送投诉内容。

(2) 投诉信息解析和过滤。系统对投诉内容进行关键字过滤、分词处理、情感倾向分析等操作，识别出投诉类型（产品质量、售后服务、价格纠纷等）。

(3) 投诉信息分发。系统根据投诉类型和投诉来源渠道，将投诉分发到相应的职能部门。

(4) 投诉信息处理。职能部门对投诉进行专业处理，填写处理意见和结果。

(5) 投诉信息归档。系统对处理结果进行归档，形成投诉处理档案。

(6) 统计分析。系统根据归档数据，生成统计报表。

## 案例二

### 阅读下列说明，回答问题 1 至问题 4

某银行网上信用卡账单管理系统在用户完成信用卡账单还款后，向用户推送一条还款成功通知消息，并自动触发积分累积操作。开发人员在检视这段代码时，发现存在一处数据库操作与业务逻辑交织在一起的问题，代码片段如下：

```java
public void processBillPayment(long billId) {
    // 查询用户信息
    User user = userDAO.findUserByBillId(billId);
    if (user == null) return;

    // 更新账单状态
    Bill bill = billDAO.findBillById(billId);
    bill.setStatus("PAID");
    billDAO.update(bill);

    // 积分累积
    Credit credit = new Credit();
    credit.setUserId(user.getUserId());
    credit.setAmount(calculateCredit(bill.getAmount()));
    credit.setType("BILL_PAYMENT");
    credit.setCreatedAt(new Date());
    creditDAO.insert(credit);

    // 发送通知
    sendNotification(user.getUserId(), "还款成功");
}
```

**问题 1**（5分）：上述代码在设计模式上存在什么问题？请说明如果使用 DAO 模式重构，将如何改进这段代码。

**问题 2**（4分）：在该系统中，数据库管理员发现一个数据异常：
某用户账单记录显示已还款（STATUS='PAID'），但积分累积记录表中没有该用户的积分记录。请分析可能的原因（至少列出 3 种）。

**问题 3**（4分）：针对上述数据异常，请设计一种机制确保数据一致性，并说明其实现原理。

**问题 4**（4分）：银行系统对数据完整性要求极高。若要保证上述业务操作的原子性，请说明数据库事务隔离级别应如何选择，并说明理由。

## 案例三

### 阅读下列说明，回答问题 1 至问题 6

某公司承接了为航空领域开发机载导航系统的任务。系统架构师决定采用容错处理来保证系统的高可靠性。系统主要由三部分组成：惯性导航单元（INU）、大气数据计算机（ADC）和姿态航向参考系统（AHRS）。三个子系统通过数据总线进行数据交换，INU 以 50Hz 的频率输出数据，ADC 以 20Hz 的频率输出数据，AHRS 以 10Hz 的频率输出数据。

系统工作时，INU 出现故障的概率为 0.05，ADC 出现故障的概率为 0.03，AHRS 出现故障的概率为 0.07。系统要求在 INU 和 ADC 都发生故障时仍能维持正常工作，在 INU 或 ADC 其中一个发生故障但 AHRS 正常时也能维持正常工作。
