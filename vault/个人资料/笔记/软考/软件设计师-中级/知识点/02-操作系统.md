# 操作系统 (D02)

> 上午题约 5-7 分

## 1. 进程三态转换

[考点] 上午选择题 | [基础]

```
     创建
      ↓
   就绪 ←————→ 运行 → 终止
     ↑          ↓
     ←—— 阻塞 ←——
```

- **就绪 → 运行**：被调度（获得 CPU）
- **运行 → 就绪**：时间片到 / 被抢占
- **运行 → 阻塞**：等待 I/O 或事件
- **阻塞 → 就绪**：I/O 或事件完成

> **关键**：阻塞态**不能直接**跳到运行态，必须经过就绪态！

## 2. 进程同步：PV 操作与前趋图

[考点] 上午选择题 | [高频]

### 信号量机制
- **P 操作（Wait/申请）**：S = S - 1，若 S < 0 则阻塞
- **V 操作（Signal/释放）**：S = S + 1，若 S ≤ 0 则唤醒一个等待进程

### 前趋图 → PV 操作
- 每条有向边 A→B 意味着 A 执行完才能执行 B
- A 完成后对 B 的信号量做 V 操作
- B 执行前对 A 的信号量做 P 操作

## 3. 死锁

[考点] 上午选择题 | [高频]

### 死锁四个必要条件（缺一不可）
1. **互斥**：资源不能共享
2. **请求保持**：拿着不放手还要新的
3. **不可剥夺**：不能强行抢走
4. **循环等待**：A 等 B，B 等 C，C 等 A

### 死锁避免公式（必考）
$$n(w-1) + 1 \le M$$

- n = 进程数
- w = 每个进程需要的最多资源数
- M = 系统至少需要的资源总数才不导致死锁

**例题**：5 个进程，每个需要 4 个资源，至少多少资源？
→ $5 \times (4-1) + 1 = 16$

**推导逻辑**：最坏情况每个进程都缺 1 个（即各持 w-1 个），此时再加 1 个资源就能让其中一个完成并释放。

### 银行家算法
- 核心：分配前先试探，分配后系统是否还处于安全状态

## 4. 页式存储管理

[考点] 上午选择题+计算 | [高频]

### 地址结构
逻辑地址 = **页号(P)** + **页内偏移(W)**

### 地址转换过程
1. 逻辑地址 → 拆分页号 + 偏移
2. 查页表 → 找到物理块号
3. 物理地址 = 物理块号 × 页面大小 + 页内偏移

> **关键**：页内偏移在转换中**不变**！

### 段页式
- 先查段表 → 再查页表 → 才访问数据
- 不用快表时需 **3 次访存**（查段表、查页表、取数）

## 5. 段式存储管理

[考点] 上午选择题 | [高频]

### 地址结构
逻辑地址 = **段号(S)** + **段内偏移(W)**

### 地址转换两步
1. **越界检查**：`段内偏移 < 段长`？否 → 越界错误 → **不能转换**
2. **地址合成**：是 → `物理地址 = 段基地址 + 段内偏移`

> **关键**：越界判断使用 **`<` 严格小于**，合法偏移范围是 `[0, 段长-1]`，共 **段长** 个值。

### 与页式对比

| 维度 | 分段 | 分页 |
|------|------|------|
| 单位大小 | **不定长**（按逻辑划分） | **定长**（如 4KB） |
| 地址结构 | (段号, 段内偏移) | (页号, 页内偏移) |
| 越界判断 | `偏移 < 段长` | `偏移 < 页大小`（恒真因定长） |
| 地址合成 | `基址 + 偏移` | `页框号 × 页大小 + 偏移` |

### 三步速判法
1. **看段号** → 找段表项的"段长"
2. **比大小** → `段内偏移 < 段长`？一眼定生死
3. **加法** → `基地址 + 偏移` = 物理地址（仅在通过检查后）

**易错点**：
- ❌ **多地址组合"任一越界则全错"**——不能放过最后一项
- ❌ **越界用 `<` 而非 `≤`**（段长 100 时偏移 100 越界）
- ❌ 误以为段号不需要检查（段号必须 `<` 段表项数）
- ❌ 数字相近误读（960 vs 1060、50 vs 500）

**一句话口诀**：偏移小于段长才算，越界三个全废一项。基址加偏移出物理地址，段表类比书章节。

## 6. 磁盘调度

[考点] 上午选择题 | [中频]

### 移臂调度算法
| 算法 | 策略 | 特点 |
|------|------|------|
| FCFS | 先来先服务 | 简单，可能很差 |
| SSTF | 最短寻道时间优先 | 可能饥饿 |
| SCAN（电梯） | 一个方向走到头再反向 | 常用 |
| C-SCAN | 单向走到头，快速返回 | 更均匀 |
| LOOK | SCAN 的改进，不到头就反向 | 更优 |

### 旋转调度
- 同一柱面，按扇区顺序访问
- 单缓冲区：读完→处理→才能读下一个（间隔一个扇区）
