## 1. Java 基础语法（Python 对照）

> 详见 13_Java语法速查（公开包未收录该引用），以下为软考最常考的语法点：

### 核心关键字速记

| 关键字 | 场景 | 示例 |
|--------|------|------|
| `public` | 类/方法公开可见 | `public void draw()` |
| `private` | 本类内部可见 | `private int count;` |
| `protected` | 本类+子类+同包 | `protected void init()` |
| `static` | 属于类（非实例） | `static void main()` |
| `abstract` | **不能实例化/无方法体** | `abstract class A` / `abstract void f();` |
| `extends` | 继承类 | `class Dog extends Animal` |
| `implements` | 实现接口 | `class A implements Runnable` |
| `void` | 方法无返回值 | `public void run()` |
| `final` | 不可变/不能重写/不能继承 | `final int MAX=100` |
| `new` | 创建对象 | `new Dog()` |
| `super` | 调用父类 | `super.method()` / `super()` |
| `this` | 当前对象 | `this.field` / `this()` |
| `null` | 空引用 | `if (obj == null)` |

### 构造方法填空模板
```java
// 无参构造
public ClassName() {
    this(defaultValue);  // 调用另一个构造器（必须在第一行）
}
// 有参构造
public ClassName(Type param) {
    this.field = param;  // this 区分参数和成员变量
}
```

## 2. C 语言语法速成（从 Python 视角）

> 软考下午第 4 题是 C 语言代码填空，这是 Python 考生的薄弱环节！

### Python → C 对照表

| 操作 | Python | C 语言 |
|------|--------|--------|
| 变量声明 | `x = 5` | `int x = 5;` ← **必须先声明类型** |
| 函数定义 | `def f(a, b):` | `int f(int a, int b) {` ← 返回值类型在前 |
| 条件判断 | `if x > 0:` | `if (x > 0)` ← **必须加括号** |
| else if | `elif x < 0:` | `else if (x < 0)` |
| for 循环 | `for i in range(10):` | `for (int i = 0; i < 10; i++)` |
| while 循环 | `while x > 0:` | `while (x > 0)` |
| 数组 | `arr = [0]*10` | `int arr[10];` |
| 数组大小 | `len(arr)` | `sizeof(arr)/sizeof(arr[0])` |
| 指针/引用 | 自动管理 | `int *p = &x;` ← 需要手动管理 |
| 空值 | `None` | `NULL` |
| 逻辑与/或/非 | `and`, `or`, `not` | `&&`, `||`, `!` |
| 三元表达式 | `a if cond else b` | `cond ? a : b` |
| 结构体 | `class` 或 `dict` | `struct { int a; float b; };` |
| 动态内存 | 自动 GC | `malloc(n * sizeof(int))` + `free(p)` |
| 字符串 | `"hello"` | `char s[] = "hello";` |
| 注释 | `#` | `//` 或 `/* */` |

### C 语言常见陷阱（Python 考生最容易错的）

1. **没有 `elif`**：只有 `else if`
2. **`=` 是赋值，`==` 是判断**：`if (x = 5)` 不报错但逻辑错误！
3. **数组不检查越界**：`arr[100]` 当数组只有 10 个元素，C 不会报错
4. **整数除法**：`5 / 2` = 2（不是 2.5！）
5. **分号结尾**：每个语句必须 `;`（这是最常见的填空坑）
6. **函数必须声明/定义顺序**：被调用的函数要出现在调用之前（或在前面声明）
7. **`return` 只能返回一个值**：不能像 Python 那样 `return a, b`

## 3. 常见算法代码模板（C语言）

### 二分查找
```c
int binarySearch(int arr[], int n, int target) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = (low + high) / 2;  // 注意整数除法
        if (arr[mid] == target)
            return mid;
        else if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;
    }
    return -1;  // 未找到
}
```

### 冒泡排序
```c
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];       // 填空点：交换
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

### 递归（阶乘）
```c
int factorial(int n) {
    if (n <= 1)      // 填空点：递归终止条件
        return 1;
    else
        return n * factorial(n - 1);  // 填空点：递归调用
}
```
