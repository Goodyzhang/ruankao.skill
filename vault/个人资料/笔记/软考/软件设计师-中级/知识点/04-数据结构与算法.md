## 1. 哈夫曼树与哈夫曼编码

[考点] 上午选择题 | [高频]

### 带权路径长度 WPL
$$\text{WPL} = \sum_{i=1}^{n} w_i \times l_i$$

其中 $w_i$ = 第 i 个叶子的权重，$l_i$ = 第 i 个叶子到根的路径长度（边数）。

### 哈夫曼构造过程
1. 把所有节点按权重从小到大放入集合
2. 取**最小的两个**合并，新节点权重 = 两者之和
3. 新节点放回集合，重复直到只剩一个节点

**示例**：权重 {10, 15, 20, 25, 30}（总频率 = 100）
- 合并 10+15=25 → 集合 {20, 25, 25, 30}
- 合并 20+25=45 → 集合 {25, 30, 45}
- 合并 25+30=55 → 集合 {45, 55}
- 合并 45+55=100 → 结束

WPL = 10×3 + 15×3 + 20×3 + 25×2 + 30×2 = 30+45+60+50+60 = **245**

### 平均码长与压缩比
| 步骤 | 公式 | 示例 |
|------|------|------|
| WPL | 合并中间节点累加 | 25+45+55+100=225（另一种算法） |
| 平均码长 | WPL ÷ 总频率 | 225÷100 = 2.25 |
| 定长码 | $\lceil \log_2 N \rceil$ | $\lceil \log_2 5 \rceil = 3$ |
| 压缩比 | (定长 - 平均) ÷ 定长 | (3-2.25)÷3 ≈ 25% |

> **注意**：WPL 有两种算法，一是叶子权重×路径长，二是合并过程中间节点累加。两种结果相等。

### 前缀编码
哈夫曼编码是**前缀编码**：任何字符的编码都不是另一个字符编码的前缀。这是为了解码时不会产生歧义。

## 2. 折半查找（二分查找）

[考点] 上午选择题+计算 | [高频]

### ASL（平均查找长度）—— 判定树法

**判定树构建**：
- 取中间位置为根节点
- 左子树 = 左边部分，右子树 = 右边部分

**ASL 计算公式**（等概率）：
$$\text{ASL}_{成功} = \frac{1}{n} \times \sum (\text{每层节点数} \times \text{层数})$$

**示例**：11 个有序元素
- 第 1 层：1 个节点
- 第 2 层：2 个节点
- 第 3 层：4 个节点
- 第 4 层：4 个节点

ASL = (1×1 + 2×2 + 3×4 + 4×4) ÷ 11 = (1+4+12+16)÷11 = **3.0**

> 判定树高度 = $\lceil \log_2(n+1) \rceil = \lceil \log_2 12 \rceil = 4$

## 3. 链表 vs 顺序表

[考点] 上午选择题 | [基础]

| 操作复杂度 | 顺序表（数组） | 链表 |
|-----------|-------------|------|
| 按位置访问 | O(1) | O(n) |
| 按值查找 | O(n) | O(n) |
| 头部插入 | O(n) | O(1) |
| 尾部插入 | O(1)* | O(1)** |
| 中间插入 | O(n) | O(1)*** |
| 删除 | O(n) | O(1)*** |

\* 不扩容时 O(1)
\** 有尾指针时 O(1)
\*** 已定位到插入/删除位置后

## 4. 二叉排序树与 AVL 树

[考点] 上午选择题 | [中频]

### 二叉排序树（BST）
- 左子树 < 根 < 右子树
- 中序遍历得到有序序列
- 最坏退化为链表：O(n)

### AVL 树（平衡二叉树）
- BST + 任意节点左右子树高度差 ≤ 1
- 保证 O(log n) 的查找效率
- 插入/删除时可能旋转（LL/RR/LR/RL）

## 5. 排序算法复杂度

[考点] 上午选择题 | [高频]

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 快速 | O(n log n) | O(n log n) | O(n²) | O(log n) | ❌ |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ |
| 堆 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ |
| 插入 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ |

> **记忆**：快排最坏 O(n²)；归并总是 O(n log n) 但需要额外空间 O(n)

## 6. 算法策略与下午第4题

> 详见 14_算法策略速查（公开包未收录该引用）

### 五大策略区分

| 策略 | 搜索方式 | 关键特征 | 经典算法 |
|------|---------|---------|---------|
| **分治** | 递归 | 子问题**不重叠** | 归并、快排、二分 |
| **贪心** | 单线推进 | **不回退**，选了就定 | 哈夫曼、Prim、Dijkstra |
| **动态规划** | **自底向上填表** | 子问题**重叠**+最优子结构 | 0-1背包、LCS、Floyd |
| **回溯** | **DFS** | 试探+回退+剪枝 | N皇后 |
| **分支限界** | **BFS/优先队列** | 活结点表+限界函数 | 0-1背包（另一种） |
