# 计算机网络 (D06)

> 上午题约 5-7 分

## 1. DNS 查询顺序

[考点] 上午选择题 | [高频]

客户端查询域名 IP 的顺序：

1. **浏览器缓存**（Chrome DNS缓存）
2. **操作系统缓存**（`hosts` 文件 与 OS DNS cache）
3. **本地 DNS 服务器**（递归查询）
4. **根域名服务器** → 顶级域 → 权威 DNS（迭代查询）

> **递归 vs 迭代**：客户端→本地 DNS 是递归（你帮我查到底）；本地 DNS→各级服务器是迭代（我告诉你下一步找谁）

## 2. IP 地址与子网划分

[考点] 上午选择题+计算 | [高频]

### 核心公式
- 子网数 = $2^{\text{借位数}}$
- 可用主机数 = $2^{\text{主机位数}} - 2$（减网络地址和广播地址）
- 块大小 = $2^{32-n}$（/n 掩码下每个子网的地址数）

### /26 块大小法
**示例**：192.168.1.0/26

- 块大小 = $2^{32-26} = 2^6 = 64$
- 子网：192.168.1.0、192.168.1.64、192.168.1.128、192.168.1.192
- 每子网可用主机：64 - 2 = 62

### 速算技巧
| CIDR | 子网掩码 | 可用 IP |
|------|---------|---------|
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /27 | 255.255.255.224 | 30 |
| /28 | 255.255.255.240 | 14 |

## 3. 特殊 IP 地址

[考点] 上午选择题 | [基础]

| 地址 | 含义 |
|------|------|
| 127.0.0.1 | 本地回环地址 |
| 169.254.x.x | DHCP 失败后 Windows 自动分配的链路本地地址 |
| 0.0.0.0 | 表示"本网络上的本主机" |
| 255.255.255.255 | 受限广播（本网段广播） |

## 4. 网络层次与协议

[考点] 上午选择题 | [基础]

| 层级 | 协议 | 设备 |
|------|------|------|
| 应用层 | HTTP/DNS/FTP/SMTP | — |
| 传输层 | **TCP** / **UDP** | — |
| 网络层 | IP / ICMP / ARP | **路由器** |
| 数据链路层 | MAC / PPP | **交换机/网桥** |
| 物理层 | — | **中继器/集线器** |

> **TCP vs UDP**：TCP 面向连接、可靠（三次握手）；UDP 无连接、不可靠但快（DNS 查询、视频流）
