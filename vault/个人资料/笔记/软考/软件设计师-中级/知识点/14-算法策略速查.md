# 算法策略速查表

> 软考下午第 4 题（C 语言算法填空）核心区分点

## 五大策略一句话区分

| 策略 | **一句话** | **搜索方式** | **关键特征** |
|------|-----------|-------------|-------------|
| **分治** | 大事化小，小事化了，再合起来 | 递归分解 | 子问题**不重叠** |
| **贪心** | 鼠目寸光，只看眼前最优 | 单线推进 | 选了不后悔，**不回退** |
| **动态规划** | 用小本本记住中间结果 | 自底向上填表 | 子问题**重叠** + 最优子结构 |
| **回溯** | 一条路走到黑，不行再退回来 | DFS（深度优先） | 试探 + 回退 + 剪枝 |
| **分支限界** | 四处开花，只追最有希望的分支 | BFS/优先队列 | 活结点表 + 限界函数 |

## 深度对比

| 维度 | 分治 | 贪心 | 动态规划 | 回溯 | 分支限界 |
|------|------|------|---------|------|---------|
| 是否全局最优 | ✅ | ❌（不一定） | ✅ | ✅（遍历全部） | ✅ |
| 存储中间结果 | 不需要 | 不需要 | **需要填表** | 只需要栈 | 需要活结点表 |
| 时间复杂度 | 一般 $O(n\log n)$ | 通常很低 | 通常 $O(n^2)$ | 通常指数级 | 通常指数级（但剪枝好于回溯） |
| 典型数据结构 | 数组/递归栈 | 优先队列 | **二维表/一维数组** | **栈（递归）** | **队列/优先队列** |

## 经典算法归属

| 算法 | 策略 | 软考考法 | 关键代码特征 |
|------|------|---------|-------------|
| 归并排序 | 分治 | 递归拆分+合并 | `merge(A, left, mid, right)` |
| 快速排序 | 分治 | 分区+递归 | `partition(A, low, high)` |
| 二分查找 | 分治 | 判定树 / ASL | `mid = (low+high)/2` |
| **哈夫曼编码** | **贪心** | 构造过程 / WPL | 每次选两个最小的 |
| Prim | 贪心 | 最小生成树 | `lowcost[i]` 数组 |
| Kruskal | 贪心 | 最小生成树 | 并查集 |
| Dijkstra | 贪心 | 单源最短路径 | 不能处理**负权边** [考点] |
| **0-1背包** | **动态规划** | 填表 | `dp[i][w] = max(dp[i-1][w], dp[i-1][w-wi]+vi)` |
| 部分背包 | 贪心 | 与 0-1 背包区分 | 按单位价值排序 |
| **LCS** | **动态规划** | 最长公共子序列 | `dp[i][j] = dp[i-1][j-1]+1 or max(...)` |
| Floyd | 动态规划 | 全源最短路径 | **三重循环** `k-i-j` |
| **N皇后** | **回溯** | 解空间树 | `isSafe()` + 递归 |
| 迷宫问题 | 回溯 | DFS 搜索路径 | `visited[][]` 标记 |
| 旅行商 | 分支限界 | BFS / 优先队列 | 下界估计 + 剪枝 |

## 下午第4题解题技巧

### 读题三步法
1. **看问题描述的关键词**：从"最优解""所有解""合并"等词判断策略
2. **看代码结构**：递归 → 分治或回溯；循环填表 → DP；循环选最优 → 贪心
3. **看数据结构**：二维数组 → 极可能是 DP；`visited` 数组 → 回溯；优先队列 → 分支限界或贪心

### 常见填空模式
```c
// 分治 —— 递归终止条件
if (left >= right) return;

// DP —— 初始化/状态转移
for (i = 1; i <= n; i++)
    for (j = 1; j <= W; j++)
        dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i]);

// 回溯 —— 剪枝条件
if (bound <= best) return;

// 贪心 —— 选择当前最优
if (a[i] < min_val) min_val = a[i];
```

### C 语言易错语法（Python 考生必看）
| Python | C 语言 |
|--------|--------|
| `for i in range(n):` | `for (i = 0; i < n; i++)` |
| `if x > 0:` | `if (x > 0)` ← 必须加括号 |
| `# 注释` | `// 注释` 或 `/* 注释 */` |
| `a = [0]*n` | `int a[n];` (需先声明) |
| `len(a)` | `sizeof(a)/sizeof(a[0])` |
| `return a, b` | 只能 `return` 一个值 |
| `max(a, b)` | `(a > b) ? a : b` (三元) 或自定义 |
| `None` | `NULL` |
| `and` / `or` / `not` | `&&` / `||` / `!` |
| `elif` | `else if` |
| 数组访问越界不报错 | **C 不检查越界！** 这是常见考点 |
