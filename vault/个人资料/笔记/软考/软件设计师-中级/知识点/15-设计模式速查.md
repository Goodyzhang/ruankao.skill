# 设计模式速查表

> 23 种 GoF 设计模式完整速查，按分类排列。软考下午第 5/6 题常考 **粗体** 标注的。

## 创建型（5种）

| 模式 | 意图 | 关键代码特征 | 频率 |
|------|------|-------------|------|
| **单例** (Singleton) | 全局唯一实例 | `private` 构造器 + `static` 实例 + `getInstance()` | 🔥 |
| **工厂方法** (Factory Method) | 延迟到子类决定具体产品 | `abstract Product factoryMethod()` | 🔥 |
| **抽象工厂** (Abstract Factory) | 创建一族相关对象 | 多个工厂方法组成工厂接口 | ⚠️ |
| **生成器** (Builder) | 分步构建复杂对象 | `buildPart1()`, `buildPart2()`, `getResult()` | ⚠️ |
| 原型 (Prototype) | 克隆对象 | `clone()` 方法 | 🟢 |

## 结构型（7种）

| 模式 | 意图 | 关键代码特征 | 频率 |
|------|------|-------------|------|
| **适配器** (Adapter) | 不兼容接口 → 兼容 | `Adapter implements Target` + 持有 `Adaptee` | 🔥 |
| **桥接** (Bridge) | 抽象与实现解耦 | `abstract class A { protected B b; }` | 🔥 |
| **组合** (Composite) | 树形结构统一处理 | `Component { add(Component), remove(Component), operation() }` | ⚠️ |
| **装饰器** (Decorator) | 动态扩展功能 | `class D extends C { protected C c; }` | 🔥 |
| **代理** (Proxy) | 控制访问 | `Proxy implements Subject` + 持有 `RealSubject` | 🔥 |
| 外观 (Facade) | 统一入口简化调用 | 一个类聚合多个子系统对象 | ⚠️ |
| 享元 (Flyweight) | 共享不变部分 | Factory 缓存已创建对象 | 🟢 |

## 行为型（11种）

| 模式 | 意图 | 关键代码特征 | 频率 |
|------|------|-------------|------|
| **策略** (Strategy) | 算法可切换 | `Context { Strategy s; setStrategy(...); }` | 🔥 |
| **观察者** (Observer) | 发布-订阅通知 | `Subject { List<Observer>; notify(); }` | 🔥 |
| **模板方法** (Template Method) | 算法骨架固定，步骤可变 | `final void templateMethod()` + `abstract void step()` | 🔥 |
| **命令** (Command) | 请求封装为对象 | `interface Command { execute(); }` | ⚠️ |
| **状态** (State) | 状态驱动行为变化 | `Context { State s; }` + `State { handle(); }` | ⚠️ |
| **迭代器** (Iterator) | 统一遍历方式 | `interface Iterator { hasNext(); next(); }` | ⚠️ |
| 责任链 (Chain of Responsibility) | 多级审批传递 | `Handler { Handler next; handle(); }` 链表结构 | ⚠️ |
| **访问者** (Visitor) | 操作与结构分离 | `interface Visitor { visitA(A); visitB(B); }` | ⚠️ |
| 备忘录 (Memento) | 快照/撤销 | `Memento { state; }` + `Caretaker` 管理历史 | 🟢 |
| 中介者 (Mediator) | 中心调度（星形） | `Mediator { colleagueChanged(); }` | 🟢 |
| 解释器 (Interpreter) | 语法规则解析 | `interpret(Context)` → 抽象语法树 | 🟢 |

## 易混淆模式对比

| 对比 | 区别点 | 判断标准 |
|------|--------|---------|
| 桥接 vs 策略 | 使用时机 | 桥接：**设计时**就分离 | 策略：**运行时**动态切换 |
| 适配器 vs 代理 | 目的 | 适配器：**转换接口** | 代理：**控制访问**（接口不变） |
| 装饰器 vs 代理 | 意图 | 装饰器：**增强功能** | 代理：**控制访问**（不增强） |
| 组合 vs 装饰器 | 结构 | 组合：一对多聚合 | 装饰器：一对一包装 |
| 工厂方法 vs 抽象工厂 | 产品数量 | 工厂方法：**单一产品** | 抽象工厂：**产品族**（多个产品） |
| 模板方法 vs 策略 | 变异方式 | 模板方法：**继承**（子类重写步骤）| 策略：**组合**（替换整个算法对象）|

## 软考下午第5/6题常见类图模式

### 判读方法：看类图结构快速识别模式

```
1. 只有一个私有构造 + 静态自引用 → 单例
2. Creator ← ConcreteCreator, Product ← ConcreteProduct → 工厂方法
3. 两个独立继承树通过组合连接 → 桥接
4. 树形递归结构（含 add/remove → 组合
5. Decorator extends Component + 持有 Component → 装饰器
6. Context 持有 Strategy 引用 → 策略
7. Subject 持有 Observer 集合 + notify() → 观察者
8. AbstractClass 有 final 模板方法 + abstract 步骤方法 → 模板方法
```
