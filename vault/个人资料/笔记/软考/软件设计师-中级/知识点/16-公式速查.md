# 软考软件设计师 公式速查手册

> 全部上午题高频计算公式，按知识域分类

## D01 计算机组成

| 公式 | 用途 | 记忆口诀 |
|------|------|---------|
| $2^k \ge n + k + 1$ | 海明码：n 位数据需要 k 位校验 | "二的 k 次方大于 n 加 k 加一" |
| 命中率 = 命中次数 ÷ 总访问次数 | Cache 命中率 | — |
| $T_{avg} = h \cdot T_c + (1-h) \cdot T_m$ | Cache 平均访问时间 | 命中 × 快 + 未中 × 慢 |
| 流水线周期 = max(各段执行时间) | 流水线周期确定 | 取最慢那段 |
| 吞吐率 = 1 / 流水线周期 | 流水线最大吞吐率 | — |

## D02 操作系统

| 公式 | 用途 | 记忆口诀 |
|------|------|---------|
| $n(w-1)+1 \le M$ | 死锁避免：n 个进程各需 w 个资源，至少 M 个资源才不死锁 | "n 乘(w减1)加 1" |
| 逻辑地址 = 页号 \| 页内偏移 | 页式存储地址拆分 | 高位页号，低位偏移 |
| 物理地址 = 块号 × 页面大小 + 页内偏移 | 地址转换 | 页偏移照抄不变 |

## D04 数据结构与算法

| 公式 | 用途 | 记忆点 |
|------|------|--------|
| $\text{WPL} = \sum w_i \times l_i$ | 哈夫曼树带权路径长度 | 每个叶子的重量 × 到根的距离 |
| $\text{平均码长} = \text{WPL} \div \text{总频率}$ | 哈夫曼编码平均码长 | — |
| 定长码长 = $\lceil \log_2 N \rceil$ | N 个字符的定长编码位数 | 向上取整 |
| 压缩比 = $(\text{定长} - \text{平均}) \div \text{定长}$ | 哈夫曼相对于定长的压缩率 | — |
| $\text{ASL}_{成功} = \frac{1}{n}\sum c_i$ | 折半查找等概率 ASL | 判定树法：各层节点数 × 层数 ÷ n |
| $\text{ASL}_{成功} = \frac{n+1}{n}\log_2(n+1)-1$ | 折半查找 ASL 公式（不要求背） | — |
| 折半查找判定树高度 = $\lceil \log_2(n+1) \rceil$ | — | — |
| $T(n) = aT(n/b) + O(n^d)$ | 分治法主定理 | — |
| 归并排序：$T(n) = 2T(n/2) + O(n)$ | → $O(n\log n)$ | 分-治-合 |
| 快排最坏：$O(n^2)$，平均：$O(n\log n)$ | — | 最坏：每次选到最小/最大 |

## D05 数据库系统

| 公式/规则 | 用途 |
|-----------|------|
| 候选关键字：看属性闭包是否能推出全部属性 | 候选码推导 |
| 无损联接判定：$R_1 \cap R_2 \to R_1$ 或 $R_1 \cap R_2 \to R_2$ | 二元分解 |
| Armstrong 公理：自反、增广、传递、合并、分解、伪传递 | 函数依赖推导 |

## D06 计算机网络

| 公式 | 用途 |
|------|------|
| 子网数 = $2^{\text{子网位数}}$ | — |
| 可用主机数 = $2^{\text{主机位数}} - 2$ | 减去网络地址和广播地址 |
| /n → 子网掩码：前 n 位为 1，其余为 0 | /26 → 255.255.255.192 |
| 块大小 = $2^{32-n}$ | /26 → 块大小 64 |
| 总地址数 = 块大小 | — |

## D07 软件工程

| 公式 | 用途 | 说明 |
|------|------|------|
| $V(G) = m - n + 2$ | McCabe 复杂度（边-节点法） | m = 边数，n = 节点数 |
| $V(G) = P + 1$ | McCabe 复杂度（判定节点法） | P = 二分支判定节点数 |
| $V(G) = R$ | McCabe 复杂度（区域法） | R = 封闭区域数（含外部） |
