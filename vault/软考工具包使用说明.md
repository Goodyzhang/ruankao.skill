# 软考工具包使用说明

当前目录作为 Obsidian Vault 与 Agent 工作区使用。默认知识库位于 `个人资料/笔记/软考/`。

## 从这里开始

- 中级学习：使用 `soft-exam-prep`，填写中级学习总计划与备考仪表盘。
- 高级学习：使用 `soft-exam-architect-prep`，填写高级学习总计划与进度看板。
- 一道题：使用 `soft-exam-question-tutor`，提供完整题干、选项和自己的作答状态。
- 完整历史对话：使用对应级别的 organizer，并明确要求整理。

错题本初始化为空。项目底稿只采集有依据的事实；虚构范文和模板不代表你的经历。归档后产生的个人笔记留在这个 Vault，不需要推送到公开 toolkit 仓库。

实际卡片时序、Grill 与归档规则以已安装 Skill 为准。完整安装和升级方法见 [项目 README](https://github.com/Goodyzhang/ruankao.skill#readme)。
